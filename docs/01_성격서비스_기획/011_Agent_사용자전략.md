## Summary

성격 서비스의 핵심 문제는 "검사 한 번 하고 이탈"하는 일회성 소비 패턴이다. 본 전략은 이를 "지속적 자기발견 여정"으로 전환하기 위해 (1) 스와이프형 일일 인사이트 피드, (2) 심리학 근거 캐릭터 시스템, (3) 타로/운명학 통합, (4) 유형 기반 커뮤니티를 4단계 Phase로 설계한다. 사용자의 진정한 JTBD는 "나를 더 잘 이해하고 일상에서 활용하고 싶다"이며, 블루오션은 "심리학 근거 + 일상 맥락 + 지속적 관계"의 교차점에 있다.

## Details

### 1. 사용자 여정 매핑

#### 1-1. As-Is: 기존 성격검사 서비스의 여정

```
[유입] → [검사 수행] → [결과 확인] → [공유/스크린샷] → [이탈]
  |         10-15분          1-3분         0-2분         영구 이탈
  |
  └── 재방문 트리거: 없음 (또는 "친구가 다시 물어볼 때")
```

| 단계 | 사용자 행동 | 감정 상태 | 서비스 제공 가치 |
|------|------------|----------|----------------|
| 유입 | SNS 바이럴, 검색 | 호기심, 가벼운 기대 | 없음 (랜딩페이지) |
| 검사 | 문항 응답 | 지루함 + 기대감 | 질문 자체의 재미 |
| 결과 | 유형 라벨 확인 | 짧은 만족감 ("맞아!") | 라벨 + 간단 설명 |
| 공유 | 캡처, SNS 게시 | 자기표현 욕구 | 공유 카드 |
| 이탈 | 탭 닫기 | 무관심 | 없음 |

**핵심 이탈 원인**: 결과가 "정적 라벨"이기 때문. "너는 XXXX야" 한 문장이면 끝. 이후 돌아올 이유가 없음.

#### 1-2. To-Be: 성격 포탈의 여정

```
[유입] → [탐색/검사] → [프로필 카드] → [인사이트 피드] → [캐릭터 대화] → [타로/운명] → [커뮤니티] → [재검사/심화]
  |         10분          즉시          매일           수시            주1회+        점진적        3-6개월
  |                                      |              |               |             |
  └──────────────────────────────────────┴──────────────┴───────────────┴─────────────┘
                              리텐션 루프: 매일 새로운 발견
```

| 단계 | 사용자 행동 | 감정 상태 | 서비스 제공 가치 | 리텐션 메커니즘 |
|------|------------|----------|----------------|---------------|
| 유입 | 검색/SNS/타로앱/고민 | 호기심 | 캐릭터가 맞이 | 첫인상 앵커링 |
| 탐색 | 설문 응답 | 몰입 | 진행 피드백 | 중간 힌트 제공 |
| 프로필 | 프로필 카드 확인 | 놀라움, 공감 | 벡터 기반 다차원 프로필 | "더 알고 싶다" 유도 |
| 인사이트 | 스와이프로 탐색 | 호기심 지속 | 맥락별 제안 (협업/갈등/커리어/회복/학습) | 매일 새 카드 |
| 캐릭터 | 대화, 질문 | 친밀감 | 심리학 기반 조언 | 관계 형성 |
| 타로/운명 | 카드 셔플, 해석 | 설렘, 기대 | 성격+운명 교차 해석 | 주기적 리딩 |
| 커뮤니티 | 그룹 참여, 고민 공유 | 소속감 | 유형 기반 공감 | 사회적 유대 |
| 재검사 | 변화 측정 | 성장 실감 | 시간별 변화 트래킹 | 장기 목표 |

#### 1-3. 세그먼트별 여정 차이

| 세그먼트 | 유입 동기 | 핵심 여정 | 리텐션 키 |
|---------|----------|----------|----------|
| **호기심 탐색자** (10-20대) | "나는 어떤 유형?" | 검사 → 프로필 → 인사이트 스와이프 | 재미, 공유 가능한 콘텐츠 |
| **자기 성장 추구자** (20-30대) | "나를 더 잘 알고 싶다" | 검사 → 인사이트 → 캐릭터 대화 → 성장 트래킹 | 깊이, 실행 가능한 제안 |
| **관계 고민자** (전 연령) | "상대를 이해하고 싶다" | 검사 → 갈등/협업 인사이트 → 커뮤니티 | 실용성, 관계 개선 경험 |
| **운명/영성 탐구자** | "타로/운세가 궁금" | 타로 → 성격 연결 → 인사이트 | 신비감, 주기적 리딩 |
| **전문 활용자** (HR/코치) | "팀원 이해 도구" | 검사 → 협업/커리어 인사이트 → 대시보드 | 업무 실용성, 팀 분석 |

### 2. 리텐션 레버: "쇼츠처럼 스와이프" 구체화

#### 2-1. 일일 인사이트 피드 ("성격 쇼츠")

**핵심 컨셉**: 유튜브 쇼츠/틱톡처럼 세로형 카드를 스와이프하며 자신에 대한 인사이트를 소비하는 UX.

**피드 구성 (일일 5-8장 카드)**:

| 카드 유형 | 내용 예시 | 소스 | 새로고침 주기 |
|----------|----------|------|-------------|
| **오늘의 인사이트** | "당신의 에너지 성향(72)은 오늘같은 회의 많은 날 특히 빛납니다" | score_vector + 요일/맥락 | 매일 |
| **성격 비교** | "당신과 같은 에너지 패턴을 가진 사람은 전체의 23%" | 통계 집계 | 매일 |
| **행동 챌린지** | "오늘 하나: 회의에서 30초 멈추고 조용한 동료에게 먼저 물어보세요" | collaboration_module | 매일 |
| **관계 팁** | "당신의 관계 성향이 높은(68) 파트너와 갈등 시 이렇게..." | conflict_module | 2-3일 |
| **커리어 힌트** | "이번 주 업무에서 당신의 의사결정 패턴을 활용해보세요" | career_module | 주간 |
| **성장 리포트** | "지난 2주간 회복 패턴이 이렇게 변했어요" | recovery_module + 히스토리 | 격주 |
| **타로 한 장** | "오늘의 카드: 별 - 당신의 회복 성향과 연결된 의미는..." | 타로 + score_vector | 매일 |
| **커뮤니티 하이라이트** | "같은 유형 그룹에서 인기 있는 고민" | 커뮤니티 집계 | 매일 |

**스와이프 UX 상세**:
- 세로 풀스크린 카드, 상하 스와이프로 다음/이전
- 카드마다 배경색/일러스트가 다름 (시각적 다양성)
- 하단에 "왜 이 제안이 나에게?" 설명 블록 (ExplanationBuilder 활용)
- 좌로 스와이프: 저장 / 우로 스와이프: 공유
- 카드 끝에 도달하면: "내일 새로운 인사이트가 기다립니다" + 알림 설정 유도

**기존 인사이트 모듈과의 연결**:
- `ContextEngine`이 5개 모듈(collaboration, conflict, learning, career, recovery)에서 인사이트 생성
- 현재는 일괄 생성 후 정적 표시 → 매일 1-2개씩 "드립" 방식으로 순차 공개로 전환
- `ExplanationBuilder`의 "Based on your..." 패턴을 카드 하단 설명으로 재활용
- score_vector의 4개 도메인(energy, decision_making, relationship, recovery)을 일일 맥락과 교차

#### 2-2. 성격 매칭

| 매칭 유형 | 설명 | 난이도 | 예상 효과 |
|----------|------|-------|----------|
| **유형 유사도** | "당신과 비슷한 프로필을 가진 사람들" | 낮음 (벡터 거리 계산) | 중간 (소속감) |
| **보완 매칭** | "당신의 약점을 보완하는 유형의 사람" | 중간 (반전 벡터 매칭) | 높음 (관계 인사이트) |
| **갈등 시뮬레이션** | "이 유형과 갈등 시 어떻게 해야?" | 중간 (conflict_module 확장) | 높음 (실용성) |
| **팀 구성 분석** | "우리 팀의 유형 분포와 시너지" | 높음 (다중 프로필 분석) | 매우 높음 (B2B 확장) |

#### 2-3. 성장 트래킹

- **재검사 알림**: 3개월/6개월 주기로 "당신이 변했을 수 있어요. 다시 확인해볼까요?"
- **변화 시각화**: score_vector 히스토리를 레이더 차트로 시간축 비교
- **성장 일기**: 인사이트 카드에 대한 사용자 메모 → 시간이 지나면 "3개월 전 당신의 메모"로 다시 표시
- **마일스톤**: "100일 연속 방문", "인사이트 50개 읽음", "프로필 3회 갱신" 등 뱃지

#### 2-4. 알림/푸시 전략

| 알림 유형 | 타이밍 | 메시지 톤 | 빈도 제한 |
|----------|-------|----------|----------|
| 일일 인사이트 | 오전 8-9시 (출근길) | "오늘의 나를 위한 한 장" | 1일 1회 |
| 성장 리마인더 | 월요일 오전 | "이번 주 행동 챌린지" | 주 1회 |
| 재검사 유도 | 90일 후 | "3개월간 당신이 달라졌을지도" | 분기 1회 |
| 커뮤니티 활동 | 그룹 내 반응 시 | "같은 유형 동료가 공감했어요" | 이벤트 기반 |
| 타로 리딩 | 매주 월요일 or 보름 | "이번 주의 카드가 준비됐어요" | 주 1회 |

#### 2-5. 리텐션 레버 종합 평가

| 레버 | 구현 난이도 | 예상 DAU 영향 | 예상 7일 리텐션 기여 | 우선순위 |
|-----|-----------|-------------|-------------------|---------|
| 일일 인사이트 피드 | 중간 | +30-40% | +15-20%p | **P0** |
| 성장 트래킹/재검사 | 낮음 | +10-15% | +5-10%p | **P0** |
| 알림/푸시 | 낮음 | +20-25% | +10-15%p | **P0** |
| 성격 매칭 (유사/보완) | 중간 | +15-20% | +8-12%p | P1 |

| 커뮤니티 | 높음 | +15-25% | +10-20%p (장기) | P2 |
| AI 에이전트 캐릭터 | 매우 높음 | +30-50% | +15-25%p | P3 |

### 3. 캐릭터 시스템

#### 3-1. Phase 1: 규칙 기반 (매크로) 캐릭터

**설계 원칙**: memo.md의 "유연하고 복잡한 매크로정도로 시작" 비전 구현.

**캐릭터 구조**:

```
[메인 캐릭터: "나래" (나를 래핑하다)]
  ├── 역할: 서비스의 얼굴, 첫 인사, 검사 안내, 결과 전달
  ├── 성격: 따뜻하지만 지적, 호기심 많음, 판단하지 않음
  ├── 시각: 중성적 일러스트 (특정 성별/연령 배제)
  └── 톤: "~해볼까요?", "흥미롭네요", "이런 면도 있을 수 있어요"

[서브 캐릭터: 맥락별 전문 페르소나]
  ├── "하모" (하모니): 관계/갈등 맥락 → conflict_module, collaboration_module
  ├── "리커" (리커버리): 회복/에너지 맥락 → recovery_module
  ├── "패스" (패스파인더): 커리어/성장 맥락 → career_module, learning_module
  └── "미스티" (미스터리): 타로/운명 맥락 → 타로 모듈 (Phase 2)
```

**매크로 대화 시나리오 (Phase 1)**:

시나리오 1: 첫 방문
```
나래: "안녕하세요! 여기 오신 건 나에 대해 궁금한 게 있어서일까요?"
  → [선택지 A] "성격이 궁금해요" → 검사 플로우로
  → [선택지 B] "그냥 둘러보러요" → 인사이트 피드 미리보기 (익명 샘플)
  → [선택지 C] "타로가 궁금해요" → 타로 플로우로 (Phase 2)
```

시나리오 2: 결과 전달
```
나래: "당신의 프로필이 완성됐어요. [프로필 카드 표시]"
나래: "에너지 쪽에서 흥미로운 패턴이 보이네요. 더 자세히 볼까요?"
  → [예] → 하모/리커/패스 중 가장 관련 높은 서브캐릭터로 전환
  → [아니요, 나중에] → "언제든 다시 오세요. 매일 새로운 발견이 기다려요."
```

시나리오 3: 재방문 인사이트
```
나래: "어제의 행동 챌린지는 어떠셨어요?"
  → [해봤어요] → "어떤 느낌이었는지 한 줄 메모 남겨볼까요?" → 성장 일기
  → [못했어요] → "괜찮아요. 오늘의 인사이트는 이거예요. [카드 표시]"
  → [관심 없어요] → "다른 맥락의 인사이트도 있어요." → 다른 모듈 카드
```

**매크로 엔진 구조**:
- 의사결정 트리(Decision Tree) 기반
- 분기 조건: score_vector 값, 방문 횟수, 마지막 활동, 시간대, 최근 본 인사이트 맥락
- 응답 템플릿: 맥락별 30-50개 문구 뱅크 (톤 정책 준수)
- 폴백: 트리 밖 입력 시 "좋은 질문이네요. 이 부분은 [관련 인사이트 카드]에서 더 자세히 다루고 있어요."

#### 3-2. Phase 2: AI Agent 캐릭터

**전환 조건**: Phase 1에서 충분한 대화 로그 축적 + 사용자 피드백 + 비용 모델 검증 후.

**단계적 전환**:

```
[정보 웹사이트] ──→ [익명 반응] ──→ [유형 그룹] ──→ [소셜 커뮤니티]

Phase 4 시작: DM, 멘토링, 유저 생성 콘텐츠
```

#### 4-2. 유형 기반 그룹 설계

**독자 네이밍**: 공식 유형 명칭(MBTI 등) 사용 불가이므로, 프로필 벡터의 지배적 패턴에 따른 독자 그룹명.

| 지배 패턴 | 그룹명 (안) | 성격 | 그룹 활동 |
|----------|-----------|------|----------|
| 고에너지 + 고관계 | "불꽃연결자" | 활발한 대화, 이벤트 주도 | 주간 토론, 챌린지 |
| 고에너지 + 저관계 | "번개사냥꾼" | 행동 지향, 실용적 공유 | 프로젝트 공유, 팁 교환 |
| 저에너지 + 고관계 | "깊은우물" | 소수 깊은 대화, 감정 공유 | 고민 상담, 일기 공유 |
| 저에너지 + 저관계 | "고요한산책자" | 관찰, 글쓰기, 콘텐츠 소비 | 글쓰기 공간, 추천 공유 |
| 고의사결정 + 고회복 | "방향제시자" | 체계적 조언, 멘토 역할 | Q&A, 가이드 작성 |
| 저의사결정 + 저회복 | "여행중인영혼" | 탐색적, 공감 기반 | 경험 나눔, 상호 응원 |

**주의**: 그룹명은 결정론적 라벨이 아닌 "지금의 성향 패턴에 기반한 공간"으로 고지. 사용자는 복수 그룹 참여 가능.

#### 4-3. 자체 유지 메커니즘

| 메커니즘 | 설명 | 효과 |
|---------|------|------|
| **유형 리더** | 그룹 내 활동적 사용자에게 "가이드" 역할 부여 | 책임감 → 지속 참여 |
| **크로스 유형 이벤트** | 다른 그룹과의 교차 토론 | 다양성 경험, 타인 이해 |
| **성장 스토리** | "나의 3개월 변화" 공유 게시판 | 동기부여, 사회적 증거 |
| **고민 릴레이** | 매주 한 그룹의 고민을 다른 그룹이 조언 | 그룹 간 연결, 신선함 |
| **유저 인사이트** | 사용자가 자신의 경험 기반 인사이트 기고 | UGC 콘텐츠 생산, 주인의식 |

#### 4-4. 멘토링 시스템

- 재검사를 통해 "성장 궤적"이 확인된 사용자 → 멘토 자격 부여
- 멘토는 같은 유형 패턴의 신규 사용자에게 "성장 선배" 역할
- 멘토의 보상: 프리미엄 인사이트 무료 이용, 특별 뱃지, 커뮤니티 내 가시성

### 5. 타로/운명 서비스 통합

#### 5-1. 비전 해석

memo.md: "타로 카드 셔플 앱 '갤럭시 타로' 차용해서 앱 출시, 타로 카드 서비스도 추가해서 서비스 '성격 웹'에 추가하는거. 운명학적 관점의 심리학적 해석을 더해서."

**핵심 차별점**: 타로를 단순 운세가 아닌 "심리학적 자기 탐색 도구"로 재해석.

#### 5-2. 성격검사 + 타로 시너지 설계

| 기존 타로 서비스 | 우리의 타로 |
|---------------|-----------|
| "오늘의 운세는..." (외부 운명) | "이 카드가 당신에게 의미하는 것은..." (내면 탐색) |
| 범용 해석 | score_vector 기반 개인화 해석 |
| 일회성 리딩 | 성격 프로필과 교차하는 누적 패턴 |
| 신비주의 톤 | 심리학적 해석 + 운명학적 관점 병행 |

**통합 여정**:

```
[타로 카드 셔플] → [카드 선택] → [범용 해석] → [성격 교차 해석] → [행동 제안]
      ↑                                              |
      |                                              ↓
      └───── [인사이트 피드에 합류] ←── [ExplanationBuilder 연결]
```

**타로 x 성격 교차 해석 예시**:

> 카드: "은둔자(The Hermit)"
>
> 범용 해석: "내면의 탐색과 홀로 있는 시간이 필요한 시기입니다."
>
> 성격 교차 해석 (energy_score: 72일 때):
> "흥미롭네요. 당신은 보통 사람들과의 교류에서 에너지를 얻는 패턴(에너지 72)이지만,
> 은둔자 카드는 지금 잠시 멈추고 혼자만의 시간이 필요할 수 있다고 말하고 있어요.
> 평소와 다른 방식의 회복이 도움될 수 있습니다."
>
> 행동 제안: recovery_module에서 "솔로 회복 전략" 카드 표시

#### 5-3. 타로 모듈 구성

| 구성 요소 | 설명 |
|----------|------|
| **카드 데크** | 메이저 아르카나 22장 (초기), 풀 덱 78장 (확장) |
| **셔플 UX** | 갤럭시 타로 스타일 3D 카드 셔플 애니메이션 |
| **해석 엔진** | 카드 의미 x score_vector x 최근 인사이트 맥락 |
| **리딩 유형** | 일일 한 장, 3카드 스프레드 (과거-현재-미래), 관계 스프레드 |
| **캐릭터 연결** | "미스티" 캐릭터가 타로 리딩 진행 |
| **누적 패턴** | 자주 뽑히는 카드 패턴 분석 → "당신이 반복적으로 마주하는 테마" |

#### 5-4. 유입 채널로서의 타로

- 타로는 성격검사보다 진입 장벽이 낮음 (설문 없이 카드 한 장)
- "타로로 유입 → 성격검사로 전환" 퍼널 설계:
  1. 타로 리딩 완료 후: "이 해석을 더 깊이 하려면, 당신의 성격 프로필이 필요해요"
  2. 성격검사 유도 → 프로필 생성 → 교차 해석 제공
  3. 교차 해석의 깊이 차이가 "성격검사를 할 이유"가 됨
- 별도 모바일 앱 (타로 전용)으로 출시 → 성격 웹으로 딥링크

#### 7-1. 사용자의 진정한 JTBD

| "팀원 이해하려고" | "팀 내 비효율의 원인이 성격 차이인지 확인하고, 실용적 해법을 얻고 싶다" |

#### 7-3. ERRC 프레임워크 (제거/감소/증가/창조)

| 전략 | 요소 | 이유 |
|------|------|------|
| **제거 (Eliminate)** | 고정된 유형 라벨링 ("너는 XXXX") | 결정론적 라벨은 법적 리스크 + 과학적으로 부정확 + 재방문 이유를 죽임 |
| **제거** | 검사 직후 바이럴 공유 유도 | MVP 비목표 + 유출되는 트래픽을 내부 리텐션으로 전환 |
| **감소 (Reduce)** | 검사 문항 수 | 진입 장벽 낮추되, 정밀도는 score_vector 정규화로 보전 |
| **감소** | "유형 분류"의 강조도 | 라벨 대신 연속적 벡터(0-100)를 시각적으로 제공 |
| **증가 (Raise)** | 심리학적 근거 설명 | ExplanationBuilder의 "Based on your..." 패턴을 모든 카드에 |
| **증가** | 맥락별 실행 가능한 제안 | 5개 인사이트 모듈의 구체적 행동 제안 |
| **증가** | 데이터 투명성/신뢰 | "왜 이 제안이 나에게" 설명 블록, 면책 고지, 비진단 고지 |
| **창조 (Create)** | 일일 인사이트 피드 (스와이프) | 재방문 메커니즘의 핵심. 기존 서비스에 없음 |
| **창조** | 심리학 근거 캐릭터 시스템 | character.ai의 재미 + 심리학의 깊이 = 독자 카테고리 |
| **창조** | 성격 x 타로 교차 해석 | 타로 시장 유입 + 성격 시장 유입의 교차점 |
| **창조** | 성장 트래킹/시간축 비교 | "나의 변화"를 시각화하는 서비스 부재 |
| **창조** | 유형 기반 공감 커뮤니티 | 성격 유형에 기반한 실질적 상호 지원 네트워크 |

#### 7-4. 비고객 타깃팅 (3계층)

블루오션 전략의 "비고객 3계층"을 성격 서비스에 적용:

| 계층 | 정의 | 우리 서비스의 비고객 | 공략 전략 |
|------|------|------------------|----------|
| **1계층: 곧 떠날 고객** | 기존 MBTI 서비스를 써봤지만 "그래서 뭐?" 상태 | "검사는 해봤지만 도움 안 됐어" | 인사이트 피드의 실용성으로 재전환 |
| **2계층: 거부하는 비고객** | 성격검사를 "비과학적"이라 거부 | "MBTI 같은 거 안 믿어" | 심리학 근거 설명, 연속적 벡터(유형 라벨 없음), 투명한 방법론 |
| **3계층: 미탐색 비고객** | 성격검사와 완전히 다른 맥락에 있음 | 타로/운세 사용자, 자기계발서 독자, 코칭 고객 | 타로 앱으로 유입, 커리어 인사이트로 유입, 캐릭터 대화로 유입 |

**3계층 비고객 공략의 구체 시나리오**:

- **타로 사용자** → 타로 앱 다운로드 → 리딩 후 "성격 교차 해석" 맛보기 → 성격검사 유도 → 풀 서비스 진입
- **자기계발서 독자** → "당신의 성격 패턴에 맞는 성장 전략" 콘텐츠 마케팅 → 검사 유도
- **관계 상담 필요자** → "파트너와의 갈등, 성격 차이 때문?" 콘텐츠 → conflict_module 체험 → 검사 유도
- **HR/팀 리더** → "팀 성향 분석 무료 리포트" → 팀 단위 검사 → B2B 파이프라인

## Key Findings

1. **핵심 이탈 원인은 "정적 라벨"**: 기존 서비스가 유형 라벨 하나 주고 끝내기 때문에 재방문 이유가 없음. score_vector 기반의 연속적 프로필 + 일일 인사이트 드립이 이를 근본적으로 해결.

2. **"쇼츠처럼 스와이프"는 기술적으로 가능하고 효과적**: 현재 5개 인사이트 모듈(collaboration, conflict, learning, career, recovery) + ExplanationBuilder가 일일 카드 콘텐츠의 엔진 역할을 할 수 있음. ContextEngine의 일괄 생성을 순차 드립으로 전환하는 것이 핵심.

3. **캐릭터 시스템은 매크로부터 시작 가능**: score_vector의 4개 도메인 값과 방문 패턴을 분기 조건으로 쓰는 의사결정 트리 + 문구 뱅크로 Phase 1 구현 가능. character.ai 대비 차별점은 "심리학 근거 + 검사 데이터 기반 개인화".

4. **타로는 독립 유입 채널이자 리텐션 레버**: 성격검사보다 진입 장벽이 낮고(설문 없이 카드 한 장), score_vector와 교차하면 기존 타로 서비스에 없는 "개인화 해석"이라는 독자적 가치 창출.

5. **커뮤니티는 "시기상조가 아닌 시기 적절"이 핵심**: MAU 10K+ / 7일 리텐션 25%+ 이전에 커뮤니티를 열면 냉각됨. 익명 반응("나도 그래요")부터 시작해 점진적으로 전환.

6. **비고객 3계층이 기존 고객보다 크다**: "MBTI 안 믿는 사람", "타로만 보는 사람", "자기계발서 독자"가 기존 성격검사 시장보다 훨씬 큰 모수. 이들을 위한 별도 진입 경로가 블루오션.

7. **MVP 005번 문서의 비목표들은 Phase 2-4에서 자연스럽게 재배치 가능**: "AI 진단 서사"는 Phase 4의 AI 캐릭터로, "소셜"은 Phase 3의 커뮤니티로, "마켓플레이스"는 멘토링/코칭으로 리프레이밍.

## Recommendations

### 즉시 실행 (Phase 1 내)
1. **ContextEngine을 "드립 모드"로 확장**: 현재 일괄 생성 구조에 `drip_schedule` 개념 추가. 매일 1-2개 인사이트를 시간차로 공개하는 스케줄러 구현.
2. **스와이프 카드 UI 프로토타입**: 인사이트 모듈 5개의 출력을 세로 풀스크린 카드 형태로 렌더링하는 프론트엔드 프로토타입.
3. **ExplanationBuilder 톤 다양화**: 현재 "Based on your..." 단일 패턴을 5-6가지 변형으로 확장하여 매일 다른 느낌.
4. **재검사 스케줄링**: 90일 주기 알림 + score_vector 히스토리 저장 + 변화 시각화 기본 구조.

### Phase 2 준비
5. **캐릭터 "나래" 의사결정 트리 설계**: 30-50개 분기의 매크로 대화 시나리오 문서화.
6. **타로 해석 엔진 프로토타입**: 22장 메이저 아르카나 x 4개 도메인 score_vector = 88가지 교차 해석 템플릿 작성.
7. **갤럭시 타로 스타일 UX 벤치마킹**: 카드 셔플 애니메이션 기술 조사.

### Phase 3-4 기반
8. **커뮤니티 전환 지표 대시보드**: MAU, 체류 시간, 리텐션, "사회적 욕구" 피드백 빈도를 실시간 추적.
9. **AI 캐릭터 비용 모델링**: LLM API 호출 비용 x 예상 대화량 시뮬레이션으로 Phase 4 진입 시점 판단 기준 확보.
