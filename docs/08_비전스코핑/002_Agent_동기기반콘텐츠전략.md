# 애니어그램 동기 기반 콘텐츠 전략
# 파운더 비전 기반 깊이 × 리텐션 설계

## 1. 애니어그램 × 비전 적합성 분석

### 1-1. "왜 그렇게 행동하는가(동기)"가 깊이 콘텐츠에 기여하는 방식

파운더 비전의 핵심은 "MBTI 알려고 왔다가 깊이 있는 심리학 분석에 호감을 느끼고 재방문"이다.
이 흐름에서 애니어그램은 두 번째 레이어로 작동한다.

**진입 훅 메커니즘:**

사용자가 MBTI 결과를 보고 나서 자연스럽게 다음 질문을 하게 된다.

> "나는 INFP인데, 왜 같은 INFP인 저 사람과 이렇게 다를까?"
> "나는 INTJ인데, 왜 어떤 날은 창의적이고 어떤 날은 완전히 경직될까?"

MBTI는 이 질문에 답할 수 없다. 애니어그램의 동기 레이어가 정확히 이 갭을 채운다.

- **MBTI가 설명하는 것**: 어떻게 에너지를 얻는가, 어떻게 정보를 처리하는가 (행동 패턴)
- **애니어그램이 설명하는 것**: 왜 그 행동을 하는가, 무엇을 두려워하는가, 무엇을 갈망하는가 (동기)

같은 INFP라도 핵심 두려움이 "가치 없는 존재가 되는 것(4유형)"인지 "불완전한 것(1유형)"인지에 따라
전혀 다른 내면을 가진다. 이 차이를 보여주는 순간 사용자는 "내가 단순히 유형 하나가 아니구나"를
경험하고 더 깊이 탐색하게 된다.

### 1-2. MBTI만으로는 제공할 수 없는 "동기 탐색" 콘텐츠의 가치

**MBTI의 한계:**
- 행동이 "왜" 발생하는지 설명하지 않는다
- 같은 유형 내에서 건강한 표현과 비건강한 표현을 구분하지 못한다
- 성장 경로가 모호하다 ("INFP는 계획을 잘 세우는 연습을 하세요" 수준)
- 시간이 지나도 유형이 변하지 않으므로 재방문 동기가 약하다

**애니어그램이 추가하는 가치:**
- "지금 나는 왜 이렇게 행동하는가"에 대한 동기 설명 — 공감도 높은 인사이트
- 건강 수준 모델: 같은 유형이라도 상태에 따라 다른 표현 → "나 요즘 어디쯤인가" 자기 모니터링
- 성장 방향(통합): "스트레스 받을 때 나는 X유형처럼 되고, 성장할 때 Y유형처럼 된다" — 행동 예측과 이해
- 날개: "나는 4w3인가 4w5인가" — 같은 유형 내에서도 미세한 탐색 욕구 자극

### 1-3. 경쟁 서비스 대비 차별점

현재 한국 MBTI 서비스들(16personalities, MBTI 공식, 각종 검사 앱)은 동기를 다루지 않는다.
"당신은 INFP입니다. INFP의 특징은..."으로 끝난다.

이 서비스의 차별점:
- "당신은 INFP이며, 내면의 동기를 보면 4유형의 특성이 강합니다. 당신이 관계에서
  자주 상처받는 이유는 A이며, 이것은 단순한 성격 문제가 아니라 핵심 두려움에서 온다."
- "같은 INFP인 4유형과 9유형은 완전히 다른 내면을 가집니다. 비교해보세요."

이 서술은 사용자가 "맞아, 나는 저 사람이랑 MBTI가 같은데 완전히 달랐어"라는
기존의 실생활 경험에 답을 준다. 설명력이 높을수록 신뢰도와 재방문이 높아진다.

## 2. 동기 기반 콘텐츠 설계

### 2-1. 9유형별 핵심 동기와 두려움 콘텐츠 구조

각 유형 콘텐츠의 기본 구조:

```
유형 콘텐츠 카드 구조
├── 핵심 갈망: "근본적으로 ~를 갈망한다"
├── 핵심 두려움: "가장 깊이 ~를 두려워한다"
├── 방어 기제: "이 두려움을 피하기 위해 ~를 한다"
├── 강점 표현: "건강할 때 ~를 잘 한다"
├── 함정 패턴: "주의가 필요할 때 ~에 빠진다"
└── 성장 초대: "~를 실험해볼 때 변화가 온다"
```

**9유형 핵심 동기/두려움 요약:**

| 유형 | 핵심 갈망 | 핵심 두려움 | 방어 패턴 |
|------|----------|------------|---------|
| 1유형 | 온전함, 선함 | 나쁘거나 불완전한 것 | 완벽주의, 비판 |
| 2유형 | 사랑받음, 필요 받음 | 원치 않는 존재가 되는 것 | 과도한 돌봄, 자기 욕구 억압 |
| 3유형 | 가치 있음, 성공 | 무가치하거나 실패한 것 | 성취 추구, 이미지 관리 |
| 4유형 | 고유한 정체성, 진정성 | 정체성 없이 평범한 것 | 감정 강화, 이상화/평가절하 |
| 5유형 | 역량, 이해 | 무능하고 압도당하는 것 | 고립, 지식 축적 |
| 6유형 | 안전, 지지 | 지지 없이 혼자인 것 | 대비, 의심, 권위에의 의존/반발 |
| 7유형 | 만족, 행복 | 고통과 결핍 | 분주함, 다양한 경험 추구 |
| 8유형 | 자율, 보호 | 통제당하고 해를 입는 것 | 직접성, 통제, 강도 |
| 9유형 | 평화, 연결 | 갈등과 분리 | 합병, 자기 의제 망각 |

이 9개 카드는 MBTI 결과 페이지 직후에 "당신의 행동 뒤에 있는 것을 탐색해보세요"로 연결된다.

### 2-2. 날개(Wing)와 본능 하위유형으로 확장되는 깊이 단계

**깊이 레벨 구조:**

```
Level 0: MBTI 유형 결과 (행동 프로필)
    ↓ "더 깊이 탐색하기"
Level 1: 애니어그램 9유형 (동기 프로필)
    ↓ "당신의 유형을 더 정밀하게"
Level 2: 날개 변형 (Wing)
    - 4w3: 표현 지향, 성취 욕구 결합 ("무대 위의 예술가")
    - 4w5: 내향적 탐색, 지식 추구 결합 ("방랑하는 철학자")
    ↓ "당신의 에너지가 향하는 곳"
Level 3: 본능 하위유형 (Instinctual Subtype)
    - 자기보존(SP): 안전, 자원, 편안함에 초점
    - 사회적(SO): 집단 내 역할과 지위에 초점
    - 성적/일대일(SX): 강렬한 연결과 융합에 초점
    ↓ "지금 당신은 어디쯤인가"
Level 4: 건강 수준 (Health Levels)
    - 건강한 표현 / 평균 표현 / 스트레스 표현
    - 현재 상태 체크 → 성장 방향 제시
Level 5: 통합/분열 방향 (Integration/Disintegration)
    - 스트레스 시 어떤 유형처럼 되는가
    - 성장 시 어떤 유형처럼 되는가
    - "성장 가이드" 형태로 구체적 실천 제안
```

각 레벨은 독립적으로 소비 가능하며, 이전 레벨이 다음 레벨의 호기심을 자극한다.
사용자는 Level 0에서 5까지 자연스럽게 "다음이 궁금해지는" 흐름을 경험한다.

### 2-3. 건강 수준 모델: 개인화 느낌과 재방문 유도

건강 수준 모델(Riso-Hudson의 9단계를 3구간으로 단순화)은 다음과 같은 리텐션 가치를 가진다.

**"지금의 나" 스냅샷 콘텐츠:**

```
건강한 표현 (건강 수준 1-3):
"4유형이 건강할 때: 창의성과 진정성이 타인을 감동시키는 예술로 피어납니다.
 자신의 고통을 승화하여 보편적 공감을 이끄는 힘이 있습니다."

평균 표현 (건강 수준 4-6):
"4유형이 평균일 때: 자신이 특별하다는 느낌에 집착하고,
 일상의 '충분함'을 보지 못한 채 더 완전한 무언가를 찾아 헤맵니다."

스트레스 표현 (건강 수준 7-9):
"4유형이 스트레스 받을 때: 감정의 소용돌이 속에서 자기혐오와 질투가 교차합니다.
 아무도 자신을 이해하지 못한다는 고립감이 깊어집니다."
```

이 구조의 리텐션 가치:
- "지금 나는 어느 구간인가?"를 주기적으로 확인하고 싶어진다 (주 1회, 월 1회 재방문)
- 상태가 달라졌을 때 새로운 인사이트를 발견한다
- "요즘 스트레스 받는 것 같은데 내 유형의 패턴인가?"라는 자기 모니터링 동기

### 2-4. 통합/분열 방향: "성장 가이드" 콘텐츠

통합/분열 방향은 추상적 개념이 아닌 구체적 성장 실천으로 서술해야 한다.

**4유형 예시:**

```
분열 방향 (스트레스 시 2유형 방향):
"당신이 극도로 스트레스 받을 때, 2유형처럼 타인에게 집착하거나
 인정받으려는 욕구가 과도해질 수 있습니다.
 이를 알아차리는 것 자체가 이미 회복의 시작입니다."

통합 방향 (성장 시 1유형 방향):
"성장의 에너지가 흐를 때, 1유형의 원칙과 행동력을 빌려옵니다.
 감정의 파도에 휩쓸리지 않고 '지금 여기서 무엇이 중요한가'를
 차분히 볼 수 있을 때, 당신의 창의성은 세상과 연결됩니다.

 이번 주 실험: 감정이 아닌 가치 기반으로 하나의 결정을 내려보세요."
```

**"성장 가이드"로서의 구체성 원칙:**
- 추상적 조언이 아닌 "이번 주/이번 달" 단위 실험 제안
- 성장과 분열 모두 판단 없이 서술 (병리적 프레이밍 배제)
- 통합 방향의 유형은 "빌려오는 자원"으로 서술 (그 유형이 되는 것이 아님)

## 3. MBTI × 애니어그램 교차 콘텐츠

### 3-1. 복합 프로필 콘텐츠 구조

**"INFP이면서 4유형인 당신의 내면" 형식:**

```
복합 프로필 카드: INFP × 4유형

제목: "내면의 우주를 탐험하는 시인"

도입:
"INFP의 깊은 공감력과 4유형의 진정성 추구가 만날 때,
 당신은 가장 섬세한 감수성을 가진 사람이 됩니다."

MBTI가 설명하는 당신:
"내향적 감정(Fi)으로 강력한 내적 가치 체계를 가지며,
 외향적 직관(Ne)으로 가능성과 연결을 탐색합니다."

애니어그램이 추가하는 당신:
"이 탐색의 이면에는 '나는 충분히 고유한가,
 진짜 나를 표현하고 있는가'라는 핵심 질문이 있습니다.
 당신의 행동을 이해하는 열쇠는 '부족함에 대한 예민함'에 있습니다."

두 유형론이 겹치는 지점:
"INFP와 4유형은 모두 진정성을 최고 가치로 둡니다.
 그러나 MBTI는 이것을 '기능 선호'로 설명하고,
 애니어그램은 이것을 '핵심 두려움에서 온 갈망'으로 설명합니다.
 같은 현상을 두 렌즈로 보면 더 선명해집니다."

성장 포인트:
"INFP의 이상주의와 4유형의 고유성 추구가 결합될 때,
 당신의 함정은 '완벽한 표현이 아니면 아무것도 하지 않는' 마비일 수 있습니다.
 1유형의 실행력을 빌려와 '불완전하게 시작하기'를 실험해보세요."
```

### 3-2. 조합이 리텐션에 기여하는 방식

**수학적 탐색 노드:**

```
MBTI 16유형 × 애니어그램 9유형 = 144개 기본 교차 프로필
MBTI 16유형 × 애니어그램 9유형 × 날개 2개 = 288개 프로필
MBTI 16유형 × 애니어그램 9유형 × 본능 3가지 = 432개 프로필
```

각 사용자는 "나의 조합" 하나를 가지지만, "친구/연인/동료의 조합"도 궁금해진다.
"우리 조합은 어떻게 상호작용하는가"로 관계 콘텐츠가 파생된다.

**리텐션 메커니즘:**

1. 자기 탐색: 내 MBTI를 알았다 → 내 애니어그램이 궁금하다 → 내 날개가 궁금하다 → 오늘의 건강 수준이 궁금하다
2. 비교 탐색: 나와 같은 MBTI인데 왜 다른가 → 애니어그램 유형이 다르구나
3. 관계 탐색: 내 연인/친구의 유형과 내 유형이 어떻게 상호작용하는가
4. 시간축 탐색: 한 달 전 나의 건강 수준 vs 지금의 건강 수준

이 4가지 탐색 방향은 서로 다른 재방문 동기를 만든다.

### 3-3. "다음에 볼 것" 연결 구조

```
콘텐츠 연결 맵

[MBTI 결과 카드]
    └─ "이 행동의 동기를 탐색하기" → [애니어그램 유형 소개]
            └─ "더 정밀하게" → [날개 변형 설명]
                    └─ "에너지의 방향" → [본능 하위유형]
                            └─ "지금 나의 상태" → [건강 수준 체크]
                                    └─ "성장 경로" → [통합/분열 가이드]
                                            └─ "우리는 어떻게 다른가" → [관계 조합 콘텐츠]
                                                    └─ "우리가 잘 되려면" → [유형 조합 성장 가이드]
```

**"쇼츠형" 소비 설계:**
각 연결은 5-7초 안에 읽을 수 있는 훅 문장으로 시작한다.

> "같은 INFP인데 왜 당신은 4유형이고 저 사람은 9유형인가? — 두 사람의 내면은 완전히 다릅니다."

이 훅이 클릭을 유도하고, 클릭 후 2-3분 분량의 깊이 있는 콘텐츠로 연결된다.

## 4. 단계별 실행 제안

### Phase 1: MBTI MVP와 병행 가능한 최소 애니어그램 콘텐츠
**타임라인: MVP 출시 직후 (8주 로드맵의 7-8주차 병행)**

**현재 코드베이스와의 관계:**

현재 `personality_type` 모델은 MBTI 16유형을 다루며, `insight` 모델은 5개 맥락(collaboration, conflict, learning, career, recovery)을 제공한다. Phase 1에서 애니어그램은 별도 모델 없이 콘텐츠 레이어로 시작한다.

**Phase 1 콘텐츠 범위:**

```
1. 9유형 소개 정적 페이지
   - 각 유형의 핵심 동기/두려움 카드 (9개)
   - "MBTI → 애니어그램 관련성 안내" 브리지 텍스트
   - 법적 경계: "공공 도메인의 기본 애니어그램 구조 활용, 특정 학파 검사 미사용" 명시

2. MBTI 결과 페이지에 "동기 탐색" 섹션 추가
   - "당신의 MBTI와 자주 결합되는 애니어그램 유형들"
   - 정적 매핑 (예: INFP는 4, 9, 1유형과 자주 결합)
   - "더 탐색하기" CTA로 애니어그램 소개 페이지로 연결

3. 각 유형의 "성장 방향" 1개 콘텐츠 카드
```

**Phase 1에서 피해야 할 것:**
- 독립 애니어그램 검사 플로우 (법적 검토, 문항 설계 전)
- 복잡한 복합 프로필 생성 로직
- 건강 수준 측정 (문항 설계 필요)

**DB 수준 변경 없음** — 정적 콘텐츠로 시작.

### Phase 2: 독립 애니어그램 탐색 + MBTI 교차 시작
**타임라인: MVP 출시 후 4-8주**

**새로운 DB 모델 도입:**

```ruby
# 설계 요구사항 (coding-expert 전달용)
EnneagramType:
  - number: integer (1-9)
  - name_ko: string
  - core_motivation_ko: text     # 핵심 갈망
  - core_fear_ko: text           # 핵심 두려움
  - defense_pattern_ko: text     # 방어 기제
  - integration_type: integer    # 통합 방향 (성장 시)
  - disintegration_type: integer # 분열 방향 (스트레스 시)
  - wing_a: integer              # 날개 A
  - wing_b: integer              # 날개 B

EnneagramProfile:
  - assessment_id: FK
  - enneagram_type_number: integer
  - wing_number: integer (nullable)
  - instinct_subtype: enum [sp, so, sx] (nullable)
  - health_level: integer (1-9, nullable)

# 교차 콘텐츠 연결
PersonalityTypeCrossProfile:
  - mbti_code: string
  - enneagram_type_number: integer
  - cross_insight_ko: text       # "INFP이면서 4유형인 당신..."
  - common_strengths_ko: text
  - common_challenges_ko: text
  - growth_guide_ko: text
```

**Phase 2 콘텐츠 범위:**
- 독립 애니어그램 동기 탐색 설문 (20-30문항, 동기 탐색 중심, 특정 학파 문항 미사용)
- 9유형 상세 프로필 (날개 포함 18개 변형)
- MBTI × 애니어그램 교차 콘텐츠 개시 (우선순위 높은 12개 조합부터)

**선택 우선순위 조합 (트래픽 기준 예상):**

```
INFP × 4유형: 감수성 깊은 탐색자
INFP × 9유형: 평화로운 이상주의자
INTJ × 5유형: 전략적 지식 탐구자
ENFP × 7유형: 가능성을 쫓는 자유인
ISFJ × 2유형: 헌신하는 보호자
ESTJ × 1유형: 원칙을 세우는 지도자
... (16×9 중 가장 상관 높은 12개부터)
```

### Phase 3: 풀 스펙 복합 프로필
**타임라인: Phase 2 출시 후 8-12주**

**완성 구조:**

```
복합 프로필 = MBTI 유형 + 애니어그램 유형 + 날개 + 본능 하위유형 + 건강 수준
예: INFP + 4유형 + w3날개 + 성적본능 + 현재 건강 수준 6 → 맞춤 성장 가이드
```

**Phase 3 콘텐츠 범위:**
- 144개 MBTI×애니어그램 교차 프로필 완성
- 27개 본능 하위유형 변형 콘텐츠 (9유형 × 3본능)
- 건강 수준 자기 체크 도구 (주기적 재방문 유도)
- "이번 달 나의 성장 가이드" 개인화 콘텐츠
- 관계 조합 콘텐츠 ("우리 유형은 어떻게 함께 성장하는가")

**캐릭터 인터랙션 연결 (파운더 비전 V3):**

Phase 3에서 각 유형에 페르소나 캐릭터를 부여한다.

```
4유형 캐릭터: 깊은 눈빛의 예술가 — "당신의 감정을 이해하는 동반자"
5유형 캐릭터: 조용한 탐구자 — "당신의 질문에 함께 파고드는 동반자"
...
```

초기에는 정적 캐릭터 이미지 + 해당 유형의 말투로 작성된 콘텐츠로 구현.
이후 AI agent 연결 시 각 캐릭터가 해당 유형의 동기 기반 대화를 구현.

## 5. 코드베이스 현황 분석 및 설계 요구사항

### 현재 코드베이스가 가진 것

```
PersonalityType: MBTI 16유형 (코드, 한국어/영어 이름, 스타일 서술)
Profile: assessment → personality_type 연결, score_vector 저장
Insight: 5개 맥락별 텍스트 콘텐츠
Question: 4개 도메인(energy, decision_making, relationship, recovery)
DomainScore: 0-100 정규화 점수
```

### 애니어그램 레이어 추가 시 코딩 전문가에게 전달할 요구사항

1. `enneagram_types` 테이블 신규 생성 (Phase 2 시작 시)
   - `personality_types`와 독립적 — 두 유형론은 다른 차원이므로 분리
   - `integration_type`, `disintegration_type` 필드로 유형 간 관계 표현

2. `enneagram_profiles` 테이블 신규 생성
   - `profiles`와 1:1 관계 (사용자 한 명이 MBTI 프로필 + 애니어그램 프로필을 가짐)
   - `wing_number`, `instinct_subtype`, `health_level`은 nullable — 심화 탐색 시 채워짐

3. `personality_type_cross_profiles` 테이블 신규 생성 (Phase 2)
   - `mbti_code × enneagram_type_number` 복합 키로 교차 콘텐츠 조회
   - 텍스트는 시드 데이터로 관리

4. `Insight` 모델의 컨텍스트 확장 검토
   - 현재: collaboration, conflict, learning, career, recovery
   - 제안: motivation (동기 탐색), growth (성장 방향) 추가 — 애니어그램 인사이트 수용

5. 점수 엔진 분리
   - 현재 `Question::DOMAINS`는 행동 중심 (MBTI용)
   - 애니어그램용 동기 탐색 문항은 별도 도메인 정의 필요
   - `question_sets` 테이블의 버전(`qset_v1`, `qset_v2`)으로 분리 가능

```
유형   통합(성장)   분열(스트레스)
```

결과적으로 9개 유형이 하나의 탐색 네트워크를 형성한다.
