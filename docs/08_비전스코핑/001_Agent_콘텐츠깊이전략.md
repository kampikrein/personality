## 1. 콘텐츠 깊이 래더 (Depth Ladder)

### 설계 원칙

파운더 비전의 핵심 은유는 "쇼츠를 계속 보듯 스와이프"다. 유튜브 쇼츠가 중독적인 이유는
단순히 짧아서가 아니라 다음 영상을 예고하는 구조 때문이다. personality 서비스의
Depth Ladder도 같은 원리로 설계한다.

- 각 레벨은 독립적으로 소비 가능하되, 다음 레벨로의 문을 항상 열어둔다.
- 사용자가 어느 레벨에서 들어오든 더 깊은 곳으로 이동할 경로가 보여야 한다.
- "나에 대한 이야기"라는 자기 관련성(self-relevance)이 모든 레벨의 공통 동력이다.

---

### Level 1: 캐주얼 (Casual Hook)

**목표**: 5초 안에 공감, 30초 안에 공유 욕구 유발

**콘텐츠 유형과 예시**

| 형태 | 예시 콘텐츠 | 비고 |
|------|------------|------|
| 한줄 성향 카드 | "INFP는 좋아하는 사람한테는 감자탕도 고급 요리처럼 느낌" | 카카오톡 공유 최적화 |
| 상황 반응 카드 | "단톡방에서 읽씹하는 이유 유형별 정리" | 밈 포맷, 댓글 유도 |
| 유형별 TMI | "ISTJ의 냉장고는 유통기한 순으로 정렬되어 있음" | 인스타그램 스토리 형태 |
| 대비 카드 | "약속 전날 vs 당일: I 유형 vs E 유형의 차이" | 두 컷 비교 이미지 |
| 오늘의 성향 한마디 | "오늘 당신의 INFJ가 원하는 것: 혼자인데 연결되어 있는 느낌" | 매일 업데이트 가능 |

**제작 난이도**: 낮음 (현재 seeds.rb 데이터에서 즉시 분해 가능)

**리텐션 기여도**: 높음 (최초 유입 및 바이럴 확산의 핵심)

**한국 MZ세대 공유 맥락**
- 카카오톡 오픈채팅, 인스타그램 스토리 저장, 트위터(현 X) RT
- "이거 완전 나잖아" 자기 확인 욕구가 공유의 주동기
- 소개팅 전 "상대방 유형 미리 파악" 실용 수요와 연결

**다음 레벨 연결 문구 예시**
> "이게 왜 그런지 알고 싶다면 →" (Level 2로 이동 유도)

---

### Level 2: 탐색 (Exploration Layer)

**목표**: 3-5분 체류, "내 유형에 대해 이 서비스가 진짜 잘 안다"는 신뢰 형성

**콘텐츠 유형과 예시**

| 형태 | 예시 콘텐츠 | 비고 |
|------|------------|------|
| 유형별 상세 설명 | 현재 seeds.rb의 strengths, caution_patterns, collaboration_style 등 | 이미 존재. 포맷 개선 필요 |
| 상황별 성향 분석 | "ENFP가 회사에서 번아웃이 오는 순간 TOP 3" | 직장/대학/연애 맥락 분류 |
| 유형별 관계 지도 | "INTJ가 ENFP를 처음 만났을 때 속으로 하는 생각" | 관계 탐색 수요 높음 |
| 나의 성향 검사 결과 | 20문항 완료 후 4개 도메인 점수 + 유형 프로필 카드 | 현재 MVP 핵심 기능 |
| 성향 별자리 | "오늘 당신 유형에게 필요한 것" 일별 큐레이션 | 재방문 훅 |

**제작 난이도**: 중간 (기존 유형 데이터 + 한국 맥락 시나리오 추가 작성 필요)

**리텐션 기여도**: 중간-높음 (체류 시간 증가, 북마크 유도)

**한국 MZ세대 공유 맥락**
- "내 유형 설명 캡처해서 단톡방에 공유" — 정확도에 놀라는 경험
- 취업/인턴 면접 준비 시 "내 강점/약점 정리" 실용 수요
- 팀 프로젝트 전 "팀원 유형 파악해서 역할 배분" 수요

**다음 레벨 연결 문구 예시**
> "왜 나는 이 패턴에서 빠져나오기 어려울까? 심리학적 이유 →" (Level 3으로 이동 유도)

---

### Level 3: 심층 (Deep Dive)

**목표**: 15-30분 체류, "이 서비스가 나를 진짜로 이해한다"는 감정 형성, 재방문 약속

**콘텐츠 유형과 예시**

| 형태 | 예시 콘텐츠 | 비고 |
|------|------------|------|
| 심리 기능 발달 분석 | "INFJ의 주기능(Ni)이 무엇인지, 스트레스 시 열등기능(Se)이 어떻게 나타나는지" | Jung 인지 기능론 기반. 심리학 전문가 검증 필요 |
| 성장 가이드 | "INTP가 감정 지능을 높이기 위한 3가지 실천 방법" | 행동 지향적, 실용적 |
| 스트레스 반응 분석 | "번아웃 왔을 때 유형별 신호와 회복 방법" | 직장/학업 맥락 높은 공감 |
| 유형 패러독스 탐구 | "ENFJ가 정작 자신을 돌보지 못하는 심리적 이유" | 자기 모순 인식 → 깊은 공감 |
| 성향 발달 스펙트럼 | "어릴 때 ESTJ와 어른이 된 ESTJ의 차이 — 어떻게 성숙하는가" | 고정 라벨이 아닌 성장 서사 |

**제작 난이도**: 높음 (심리학적 근거 필요, 심리학 전문가 협업 필수)

**리텐션 기여도**: 매우 높음 (북마크 재방문, 시리즈 완독 유도)

**한국 MZ세대 공유 맥락**
- "이 글 읽고 나 왜 이러는지 이해됐어" — 자기 이해 브레이크스루 경험
- 상담받기 전 예비 자료로 저장하는 수요
- "내 친구한테 보여주고 싶다" 형태의 타인 이해 수요

**다음 레벨 연결 문구 예시**
> "당신의 유형이 팀 안에서 어떻게 작동하는지, 더 정밀한 분석 →" (Level 4로 이동 유도)

---

### Level 4: 전문 (Expert Layer)

**목표**: 반복 재방문 앵커, 구독/회원 전환, 커뮤니티 참여 시작점

**콘텐츠 유형과 예시**

| 형태 | 예시 콘텐츠 | 비고 |
|------|------------|------|
| 유형 간 관계 역학 분석 | "INTJ + ENFP 커플이 장기적으로 성장하려면 무엇이 필요한가" | 소개팅/연애 수요 직결 |
| 팀 역학 분석 | "스타트업 팀에 ENTP 2명, ISTJ 1명이 있을 때 발생하는 갈등 패턴과 해결법" | 직장 수요 직결 |
| 개인 맞춤 인사이트 | 검사 결과 + 누적 행동 데이터 기반 "당신만의 성향 보고서" | 개인화 기술 필요 (Phase 2-3) |
| 시리즈 콘텐츠 | "16유형의 돈 쓰는 방식 전체 시리즈" (16개 연재) | 완독 유도, 북마크 앵커 |
| AI 캐릭터 대화 | "내 유형 캐릭터에게 고민 상담" | 파운더 비전 V3. Phase 3 기술 구현 필요 |

**제작 난이도**: 매우 높음 (개인화 기술 + 전문 콘텐츠 기획 + 지속 업데이트 운영)

**리텐션 기여도**: 최고 (앵커 기능 — 이 콘텐츠 때문에 반드시 돌아옴)

**한국 MZ세대 공유 맥락**
- 커뮤니티 공유 ("이 시리즈 진짜 잘 만들었다 — 링크 공유")
- 직장/대학 동아리 팀빌딩 자료로 활용
- "나만 알고 싶다"는 독점 정보 감각 제공

## 2. 리텐션 콘텐츠 전략

### 2-1. 매일/매주 재방문 유도 구조

**일별 콘텐츠 (Daily Hook)**

"오늘의 성향 카드"를 Level 1 형태로 매일 업데이트한다.

```
[월] "이 유형이 월요일 아침에 하는 생각"
[화] "회의 중 이 유형이 속으로 하는 말"
[수] "이 유형의 에너지가 가장 높은 시간대"
...
```

핵심 설계: 사용자가 "오늘 내 유형 카드가 올라왔을까?"라는 기대로 방문하도록 만든다.
이는 알림 없이도 자발적 재방문을 유도하는 가장 저비용 구조다.

**주별 콘텐츠 (Weekly Series)**

Level 3-4 시리즈를 주 1-2편 연재한다.

```
예시 시리즈:
- "유형별 번아웃 사이클" (16편, 주 2편 → 8주 완결)
- "16유형이 스트레스받을 때 나타나는 신체 신호" (16편)
- "유형별 이상적인 연애 방식" (16편)
```

한국 MZ세대에게 효과적인 이유: 웹툰/시리즈 문화에 익숙하고, "다음 편"을 기다리는
경험이 자연스럽다. "아직 내 유형 편이 안 올라왔다"는 기대감이 리텐션을 만든다.

---

### 2-2. 쇼츠형 콘텐츠 연결 전략 (Hook & Bridge)

**핵심 원리: 현재 콘텐츠가 다음 콘텐츠를 예고해야 한다.**

Level 1 카드 → Level 2 설명의 연결 예시:
```
[카드] "ENFP는 왜 항상 새 프로젝트를 시작하고 마무리를 못 하나"
[하단 링크] "이게 심리학적으로 어떤 의미인지 → ENFP의 Ne 기능 이해하기"
```

Level 2 설명 → Level 3 심층의 연결 예시:
```
[설명 말미] "하지만 진짜 문제는 다른 곳에 있다. 번아웃이 왔을 때
ENFP에게 일어나는 일 →"
```

이 구조는 "더 보기"가 아니라 "이걸 알면 저게 이해된다"는 인식 구조다.
자기 이해 욕구를 가진 사람은 이 연결을 따라 자연스럽게 더 깊이 들어간다.

---

### 2-3. 한국 MZ세대가 공유하는 콘텐츠 형태

분석한 한국 MBTI 문화의 공유 동기는 크게 3가지다.

**1) 자기 확인 (Self-Validation)**
"이거 완전 나잖아" — 정확히 맞았다는 쾌감에서 공유 욕구 발생.
설계 방향: 구체적일수록 강하다. "INFP" 보다 "혼자 있는데 외롭지는 않지만
연결되고 싶은 그 묘한 감정"이 더 강하게 공유된다.

**2) 타인 이해 (Other-Understanding)**
"내 친구/연인/팀원이 왜 이러는지 이제 이해됨" — 관계 갈등 해소 욕구.
설계 방향: "이 유형의 사람이 이렇게 행동하는 이유" 포맷이 효과적.
소개팅 준비, 팀 프로젝트, 가족 갈등 맥락으로 구체화.

**3) 자기 소개 도구 (Identity Signal)**
"나는 INFJ야" — 유형을 자기소개의 약식 언어로 사용하는 문화.
설계 방향: 유형 카드를 프로필 이미지처럼 공유 가능하게 만든다.
"당신의 유형 카드를 저장하세요" CTA가 바이럴 확산의 핵심이다.

## 3. 현재 대비 갭 분석

### 현재 MVP가 커버하는 범위

현재 `db/seeds.rb`와 `005_Plan_법률우선_MVP_설계.md`를 기준으로 현황을 정리한다.

**보유 자산**
- 16유형 기본 데이터: character_name, summary, strengths, caution_patterns,
  collaboration_style, conflict_style, learning_style, career_hints, recovery_style
- 20문항 설문 (4도메인 x 5문항): qset_v1
- 점수 엔진 설계: 0-100 정규화, 프로필 벡터 출력
- 인사이트 모듈 설계: 협업/갈등/학습/커리어/회복 5개 맥락

**현재 Depth Ladder 커버리지**

| 레벨 | 설명 | 현재 커버 여부 |
|------|------|--------------|
| Level 1 (캐주얼) | 한줄 카드, 밈, 바이럴 공유 콘텐츠 | 없음 (0%) |
| Level 2 상단 (탐색) | 유형별 상세 설명, 맥락별 분석 | 원재료 있음 (50%) — 포맷/UX 미완 |
| Level 2 하단 (탐색) | 성향 검사 + 결과 프로필 카드 | 설계 완료, 구현 진행 중 (70%) |
| Level 3 (심층) | 심리학적 근거 분석, 성장 가이드 | 없음 (0%) |
| Level 4 (전문) | 유형 간 관계, 팀 역학, 개인화 | 없음 (0%) |

**핵심 갭: Level 1 부재**

가장 즉각적인 문제는 Level 1이 없다는 것이다. 현재 사용자 진입 경로는
"성향 검사 → 결과 확인"의 단선 구조다. 이 구조에서 검사를 완료하지 않은
사용자는 볼 수 있는 것이 없다. Level 1 카드 콘텐츠가 없으면 검사 시작 전 이탈을
막을 수 없다.

**갭 우선순위 매트릭스**

| 갭 | 비전과의 거리 | 제작 난이도 | 우선 해결 여부 |
|----|------------|-----------|--------------|
| Level 1 카드 콘텐츠 부재 | 매우 큼 | 낮음 | 최우선 |
| Level 2 포맷/UX 미완 | 큼 | 중간 | 우선 |
| 재방문 유도 구조 없음 | 매우 큼 | 중간-높음 | Phase 2 |
| Level 3 심층 콘텐츠 없음 | 큼 | 높음 | Phase 2-3 |
| Level 4 개인화/관계 분석 없음 | 중간 | 매우 높음 | Phase 3 |

---

## 4. 단계별 실행 제안

### Phase 1: MVP 완성 (현재 → 출시)

**목표**: 검사를 완료한 사람이 "이 서비스는 나를 잘 안다"고 느끼게 만드는 최소 경험

**즉시 가능한 작업**

1. **Level 1 캐주얼 카드 20개 제작**
   - 현재 seeds.rb의 16유형 데이터에서 각 유형의 summary + caution_patterns를
     기반으로 즉시 분해 가능
   - 형태: "유형별 TMI" 5개 + "상황 반응" 5개 + "대비 카드" 10개
   - 공유 버튼 포함한 카드 UI 필요 (UI/UX 전문가 협업)

2. **Level 2 결과 페이지 콘텐츠 강화**
   - 현재 유형 설명에 "한국 직장/대학 맥락" 시나리오 추가
   - 예: "이 성향의 사람이 팀 프로젝트에서 자주 듣는 말"
   - 기존 collaboration_style, conflict_style 필드에서 즉시 파생 가능

3. **Level 2 → Level 3 연결 고리 삽입**
   - 결과 페이지 말미에 "더 깊이 이해하기" 섹션 추가
   - Phase 2에서 채워질 심층 콘텐츠를 예고하는 "Coming Soon" 형태로 시작

**Phase 1 KPI**
- 검사 완료율: 70% 이상
- 결과 페이지 공유율: 20% 이상 (Level 1 카드 포함 시)
- 7일 재방문율: 20% 이상 (005_Plan 기존 목표와 일치)

---

### Phase 2: 리텐션 구축 (출시 후 4-8주)

**목표**: "이 서비스에 다시 오면 새로운 걸 알 수 있다"는 기대 형성

**추가 작업**

1. **일별 콘텐츠 큐레이션 시스템**
   - "오늘의 성향 카드" 자동 순환 시스템
   - 기술: 간단한 스케줄러 + Level 1 카드 풀(30개 이상) 필요
   - Level 1 카드 제작 → 코딩 전문가에게 순환 로직 구현 요청

2. **Level 3 심층 콘텐츠 시리즈 시작**
   - "유형별 번아웃 신호와 회복법" 16편 연재 시작
   - 첫 2주: INFP, ENFP, INFJ, INTJ (온라인에서 관심도 높은 유형 우선)
   - 심리학 전문가 검증 필수 (Jung 기능 발달 이론 기반)

3. **관계 탐색 콘텐츠 시작**
   - "이 유형과 저 유형이 만나면" 형태의 2인 관계 카드
   - 소개팅/연애 수요 직접 연결 → 공유율 높음
   - 16 x 16 = 256 조합이지만, 주요 16쌍부터 시작

**Phase 2 KPI**
- 월간 재방문율: 40% 이상
- 시리즈 콘텐츠 완독율: 30% 이상
- 사용자 체류 시간: 평균 5분 이상

---

### Phase 3: 성격 포탈 완성 (8주 이후)

**목표**: "성격에 관해 궁금하면 여기로" 포지셔닝 확립

**장기 작업**

1. **Level 4 개인 맞춤 인사이트**
   - 누적 방문 행동 + 검사 결과 기반 개인화 리포트
   - "당신이 지금까지 본 콘텐츠 패턴으로 본 당신의 성향"
   - 기술적 복잡도 높음 — 코딩 전문가 선도 설계 필요

2. **AI 캐릭터 인터랙션 (파운더 비전 V3)**
   - 각 유형별 캐릭터가 사용자와 대화
   - Phase 3 초기: 규칙 기반 챗봇 (스크립트 설계가 핵심)
   - Phase 3 후기: 실제 LLM 기반 개인화 캐릭터
   - 캐릭터 스크립트는 현재 seeds.rb의 유형 데이터를 핵심 재료로 활용

3. **커뮤니티 기능 (파운더 비전 V4)**
   - "같은 유형끼리 모여 이야기하는 공간"
   - 진입점: Level 4 시리즈 콘텐츠의 댓글 → 유형별 스레드 → 커뮤니티
   - personality 사이트를 유입 창구로 하는 소셜 레이어

**Phase 3 KPI**
- 월간 활성 사용자 재방문율: 60% 이상
- 콘텐츠 생산 사용자 비율(커뮤니티): 5% 이상
- AI 캐릭터 세션 당 대화 턴: 5회 이상

## 부록: 경쟁 서비스 대비 차별화 포지셔닝

현재 경쟁 서비스 분석(001_Research)을 기반으로 공백을 정리한다.

| 경쟁 서비스 | 강점 | 약점 | personality의 기회 |
|------------|------|------|------------------|
| 16personalities | 글로벌 인지도, Level 2 완성도 높음 | Level 1 공유 약함, Level 3-4 없음 | 한국 맥락 Level 1 + Level 3 차별화 |
| 푸망(나BTI) | Level 1 강함, 모바일 최적화 | Level 2-4 전무, 학문적 깊이 없음 | Level 2-4로 깊이 차별화 |
| 한국MBTI심리연구소 | 공신력, Level 3-4 깊이 | Level 1 없음, 접근성 낮음, 비용 | Level 1 + 무료 접근성 + 한국 맥락 |
| 테스트모아/하로 | 접근성, 한국어 | 일회성 소비, 재방문 없음 | 리텐션 구조가 없는 시장 공백 |

**결론**: 현재 한국 시장에 Level 1-2의 가벼운 접근성과 Level 3-4의 심층 깊이를
동시에 제공하는 서비스가 없다. 이것이 personality의 핵심 차별화 공간이다.
