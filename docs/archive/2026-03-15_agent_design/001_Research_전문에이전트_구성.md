# Personality 프로젝트 전문 에이전트 구성 연구

## Research Overview

### Background & Motivation
personality 웹 서비스는 성격 유형 탐색(MBTI 방식, 애니어그램 방식 등)을 통해 자기 이해와 타인 수용을
돕는 서비스이다. 이 프로젝트의 개발 과정에서 각 도메인 전문가의 관점을 반영하기 위해
Claude Code 커스텀 에이전트를 활용하려 한다.

5개 에이전트를 구성한다:
1. **심리학 전문가** — 학문적 근거 기반 성격 이론 자문 (항상 논문·이론 인용)
2. **MBTI 전문가** — 한국 MBTI 대유행 트렌드 인지, 서비스 설계 관점
3. **애니어그램 전문가** — 애니어그램 체계 기반 설계
4. **코딩 전문가** — Rails 백엔드 구현 전문
5. **UI/UX 전문가** — 프론트엔드 설계 및 구현 전문

### Research Scope
- Claude Code `.claude/agents/*.md` 파일 형식 및 최적 설정 조사
- 전문가 페르소나를 가진 AI 에이전트의 프롬프트 설계 방법론
- 각 도메인(심리학, MBTI, 애니어그램, 코딩, UI/UX)의 핵심 지식 체계
- 기존 프로젝트 기획 문서(법률우선 MVP 설계 등)와의 정합성

### Research Perspectives
1. **Claude Code 에이전트 시스템 최적화** — 파일 형식, 도구 제한, 모델 선택, 권한 설정 등 기술적 설정 최적화
2. **전문가 페르소나 프롬프트 설계** — 고유한 관점·말투·판단 기준을 가진 에이전트 프롬프트 엔지니어링 방법론
3. **도메인별 핵심 지식 체계** — 5개 에이전트 각각이 갖춰야 할 필수 도메인 지식과 차별화 포인트
4. **프로젝트 컨텍스트 정합성** — personality 프로젝트의 기존 기획·설계 문서와 에이전트 설계의 연동

## Preliminary Findings

### Claude Code 에이전트 시스템 (사전 조사 완료)

Claude Code 커스텀 에이전트 파일 형식:
- **위치**: `.claude/agents/*.md` (프로젝트 레벨) 또는 `~/.claude/agents/*.md` (사용자 레벨)
- **형식**: YAML frontmatter + Markdown body (시스템 프롬프트)
- **필수 필드**: `name`, `description`
- **선택 필드**: `tools`, `disallowedTools`, `model`, `permissionMode`, `maxTurns`, `skills`, `memory`, `isolation`
- **모델 옵션**: `sonnet`, `opus`, `haiku`, `inherit` (기본값: inherit)
- **도구 제한**: allowlist (`tools: Read, Grep, Glob`) 또는 denylist (`disallowedTools: Write, Edit`)
- **호출 방식**: description 기반 자동 위임, 사용자 명시 요청, CLI 플래그
- **제약사항**: 서브에이전트는 다른 서브에이전트 생성 불가, 부모 대화 히스토리 미상속

### 프로젝트 컨텍스트 (사전 조사 완료)

기존 프로젝트 기획 문서에서 확인된 핵심 원칙:
- **철학**: 자기 이해, 타인 수용, 자유 추구
- **법적 경계**: 공식 MBTI/애니어그램 검사 문항·브랜드 표현 미사용, 독자적 문항·척도·보고서
- **MVP 구성**: 문항 엔진, 점수 엔진, 프로필 컴포저, 인사이트 모듈, 신뢰/컴플라이언스 레이어
- **기술 스택**: Ruby on Rails
- **데이터 모델**: 도메인 기반 프로필 벡터(0-100), 유형 강제 없음

## Parallel Execution Instructions

### Perspective 1: Claude Code 에이전트 시스템 최적화

**조사 목표**: 5개 에이전트 각각에 최적화된 Claude Code 에이전트 설정을 도출한다.

**조사 항목**:
1. **도구(tools) 설정 최적화**:
   - 심리학/MBTI/애니어그램 전문가: 읽기 전용 에이전트가 적합한가, 쓰기 권한이 필요한가?
   - 코딩 전문가: 어떤 도구 조합이 최적인가? (Read, Write, Edit, Bash, Glob, Grep)
   - UI/UX 전문가: 프론트엔드 작업에 필요한 도구는?
   - WebSearch/WebFetch가 필요한 에이전트는?
2. **모델(model) 선택**:
   - 각 에이전트의 작업 복잡도에 따른 최적 모델 선택 기준
   - 비용 대비 성능 최적화 (haiku vs sonnet vs opus)
3. **권한(permissionMode) 설정**:
   - 자문 역할 에이전트 vs 구현 역할 에이전트의 권한 차이
4. **memory 설정**: 각 에이전트가 세션 간 기억을 유지해야 하는가?
5. **skills 연동**: 기존 스킬(.claude/skills/)과의 연동 필요성
6. **maxTurns 설정**: 각 에이전트의 적정 작업 범위 제한

**참고 파일**:
- `.claude/agents/` 디렉토리 (현재 비어있음 — 신규 생성)
- `.claude/skills/` 디렉토리 (기존 스킬 확인)
- 사전 조사에서 확인한 Claude Code 에이전트 시스템 사양

**출력 형식**: 에이전트별 추천 설정 테이블 + 근거

### Perspective 2: 전문가 페르소나 프롬프트 설계

**조사 목표**: 5개 에이전트 각각이 고유한 관점·말투·판단 기준을 가지도록 하는 프롬프트 설계 방법론을 도출한다.

**조사 항목**:
1. **페르소나 정의 프레임워크**:
   - 전문가 정체성 (who): 학력, 경력, 전문 분야
   - 사고 방식 (how): 판단 기준, 우선순위, 분석 프레임워크
   - 소통 스타일 (style): 말투, 용어 선택, 설명 깊이
   - 가치관 (why): 무엇을 중요하게 여기는가, 어떤 점에서 타협하지 않는가
2. **고성능 프롬프트 패턴**:
   - Chain-of-thought 유도 패턴
   - 전문가 관점 고정(anchoring) 기법
   - 할루시네이션 방지: 근거 인용 강제, "모르겠다" 허용
   - 에이전트 간 관점 충돌 시 행동 규칙
3. **에이전트별 페르소나 초안**:
   - 심리학 전문가: 학문적 근거 필수, APA 스타일 인용, 임상 vs 성격심리학 구분
   - MBTI 전문가: 한국 문화적 맥락, 저작권 인지, 대중적 소통
   - 애니어그램 전문가: 체계적 유형론, 성장 방향 강조
   - 코딩 전문가: Rails 컨벤션, 테스트 중심, 실용주의
   - UI/UX 전문가: 사용자 중심 설계, 접근성, 한국 시장 UX 트렌드
4. **프롬프트 안티패턴**: 피해야 할 설계 실수

**외부 조사**:
- WebSearch로 "AI agent persona prompt engineering best practices" 조사
- WebSearch로 "system prompt design for domain expert AI" 조사

**출력 형식**: 페르소나 프레임워크 + 에이전트별 페르소나 설계 초안

### Perspective 3: 도메인별 핵심 지식 체계

**조사 목표**: 5개 에이전트 각각이 갖춰야 할 핵심 도메인 지식과 차별화 포인트를 정리한다.

**조사 항목**:
1. **심리학 전문가 도메인 지식**:
   - 성격심리학 주요 이론: Big Five(OCEAN), 특성 이론(Allport, Cattell), 유형론 비판
   - 심리측정학 기본: 신뢰도, 타당도, 표준화, 규준
   - 성격 검사 도구: NEO-PI-R, HEXACO, TCI 등
   - 윤리적 고려사항: 바넘 효과, 확증 편향, 라벨링 위험
   - 이 에이전트가 다른 에이전트와 구별되는 핵심: "항상 학문적 근거 제시"

2. **MBTI 전문가 도메인 지식**:
   - MBTI 이론 체계: Jung의 심리 유형론, 4가지 선호 지표, 16유형
   - 한국 MBTI 트렌드: MZ세대 문화, 소개팅/채용/팀빌딩 활용, 밈화 현상
   - MBTI 비판과 한계: 학문적 비판, 재검사 신뢰도 이슈, Forer 효과
   - 저작권/법적 이슈: The Myers-Briggs Company 저작권 범위, 우회 전략
   - 한국 MBTI 서비스 경쟁사 분석: 16personalities, 어세스타 등
   - 이 에이전트가 구별되는 핵심: "한국 문화적 맥락에서의 MBTI 활용 전문성"

3. **애니어그램 전문가 도메인 지식**:
   - 애니어그램 체계: 9가지 유형, 날개(wing), 통합/분열 방향, 본능 하위유형
   - 주요 학파: Riso-Hudson, Naranjo, Palmer, Ichazo-Arica
   - 성장 모델: 각 유형의 건강 수준(건강-보통-비건강)
   - 저작권/법적 이슈: 애니어그램 자체는 공유 도메인이나 특정 검사 도구는 보호
   - MBTI와의 차이점: 동기 기반 vs 행동 기반
   - 이 에이전트가 구별되는 핵심: "성장과 변화 가능성 강조"

4. **코딩 전문가 도메인 지식**:
   - Ruby on Rails 전문성: 컨벤션, ActiveRecord, MVC, API 설계
   - 이 프로젝트의 기술 스택 맥락: Rails 7+, PostgreSQL, RSpec
   - 성격 서비스 특화 기술 요구: 문항 엔진, 점수 계산, 프로필 벡터
   - 테스트 전략: TDD, RSpec, 팩토리, 통합 테스트
   - 이 에이전트가 구별되는 핵심: "실용적 코드 구현 + Rails 컨벤션 준수"

5. **UI/UX 전문가 도메인 지식**:
   - UX 설계 원칙: 사용자 리서치, 정보 구조, 인터랙션 디자인
   - 성격 검사 UI 패턴: 진행률 표시, 문항 네비게이션, 결과 시각화
   - 한국 시장 UX 트렌드: 카카오/네이버 디자인 언어, 모바일 퍼스트
   - 접근성: WCAG 2.1, 색상 대비, 스크린리더 호환
   - 프론트엔드 기술: Hotwire/Turbo (Rails 연동), Tailwind CSS
   - 이 에이전트가 구별되는 핵심: "사용자 감정 흐름 설계 + 한국 시장 최적화"

**외부 조사**:
- WebSearch로 각 도메인의 핵심 참고 자료 확인
- 특히 한국 MBTI 트렌드, 애니어그램 학파별 차이점 조사

**출력 형식**: 에이전트별 필수 지식 체계 + 차별화 매트릭스
