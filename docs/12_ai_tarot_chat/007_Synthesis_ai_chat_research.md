# AI 타로 해석 채팅 — 사전 연구 종합

## 1. Executive Summary

3축 병렬 연구(기술 구현 가능성 / 사용자 기대·경험 / 경쟁 서비스 분석)의 교차 분석에서 도출된 핵심 결론:

1. **"공명 격차" 해소가 제품의 본질적 과제**: AI와 인간 리더의 콘텐츠 정확도는 동등(78% vs 79%)하지만, 감정적 공명은 3.2배 차이. "정확한 해석"이 아닌 "감정적으로 내 이야기 같은 해석"이 품질 기준.
2. **삼각 차별화 확정**: 물리 셔플(경쟁사 전무) + 맥락 지속성(업계 공통 약점) + ReflectivePrompts(바넘 효과 방어) — 이 세 축은 각각 기술적으로 실현 가능하고, 사용자가 원하며, 경쟁사가 갖추지 못함.
3. **비용이 장벽이 아님**: 1회 해석 $0.003~$0.05, 월 구독 $5~$10 대비 COGS 1~5%. 관대한 무료 티어 + 프리미엄 모델이 가능.
4. **한국 시장 PMF 강력**: 타로 전용 앱 공백 + 헬로우봇이 검증한 캐릭터 AI 타로 패턴(150~200억/년) + MZ 72% 집중 + "맞는 말이긴 한데 내 이야기 같진 않아" 피드백 = 개인화 AI 타로의 최적 진입점.

## 2. 3축 교차 분석

### 2.1 축 수렴 — 3축이 동시에 가리키는 기회

| 수렴 패턴 | 기술(축1) | 사용자(축2) | 경쟁(축3) | 시사점 |
|----------|----------|-----------|----------|--------|
| **맥락 지속성** | Hybrid 패턴(Sliding Window + RAG + pgvector) 기술적으로 구현 가능. 기존 `Reading` 엔티티가 데이터 구조 제공 | "세션 간 기억 부재"가 사용자 불만 1위. ChatGPT 직접 사용자가 대화 기억을 핵심 만족으로 언급 | 8개 경쟁사 중 Lunanul만 Reflection Thread 보유. 나머지 전체 세션 독립 | **가장 확실한 차별화 + 리텐션 드라이버** |
| **ReflectivePrompts 통합** | 5레이어 프롬프트 아키텍처에 자연스럽게 통합 가능. 기존 22+4개 질문을 AI 개인화 입력으로 활용 | 바넘 효과가 사용자 실망의 핵심 원인. 개방형 질문으로 사용자 맥락 수집 → 개인화 강화 | 어떤 경쟁사도 확증 편향 완화를 설계에 반영하지 않음 | **바넘 효과 방어 + 개인화 이중 기능으로 구조적 품질 차별화** |
| **물리 셔플 → AI 해석 플로우** | Flutter Flame 엔진 이미 구현 완료. 셔플 결과(DrawnCardInfo)가 AI 프롬프트 입력으로 직결 | 사용자는 "의식(ritual)" 경험을 기대. 일방적 해석보다 참여형 경험 선호 | 8개 서비스 모두 "탭하여 선택". 물리 셔플은 복제 어려운 기술적 해자 | **유일한 글로벌 하드 차별화 — 체화된 경험에서 AI 해석으로의 자연스러운 전환** |
| **비용 구조** | 텍스트 $0.003~$0.05/회, 프롬프트 캐싱으로 90% 추가 절감 | 사용자는 무료~저가 기대 (인간 상담 대비 90%+ 절감이 만족 요인) | 경쟁사 월 $5~$13 구독. 한국은 건당 과금 선호 | **관대한 무료 티어 + 프리미엄 하이브리드 모델이 비용적으로 가능** |

### 2.2 축 긴장 — 3축이 충돌하는 지점

| 긴장 패턴 | 설명 | 해결 방향 |
|----------|------|----------|
| **해석 깊이 vs 비용** | 깊은 해석(Opus $5/$25/MTok) vs 저비용(Haiku $0.25/$1.25/MTok). 사용자는 깊이를 원하지만 비용은 가격에 전가 | Sonnet($3/$15)이 품질/비용 최적점. 무료 티어는 Haiku, 프리미엄은 Sonnet/Opus 계층화 |
| **개인화 vs 프라이버시** | 깊은 개인화에는 사용자 정보 필요. 한국 사용자는 프라이버시 중시 | ReflectivePrompts로 자발적 맥락 제공 유도 (명시적 개인정보 수집 없이 대화 과정에서 맥락 축적) |
| **멀티모달 경험 vs 단계적 구현** | 사용자는 음성/이미지/영상 경험 기대. 비용은 텍스트 대비 10~100배 | 텍스트 MVP → 인앱 리포트(추가 비용 $0) → TTS($0.03) → 이미지($0.04) → 영상($0.25) 단계적 확장 |
| **사조 다양성 vs 복잡도** | 심리학적/상징학적/영적 3사조 제공은 블루오션이나 프롬프트 관리 복잡도 증가 | 시스템 프롬프트의 "전통/사조" 레이어를 교체 가능 모듈로 설계. MVP는 심리학적 관점(기존 ReflectivePrompts 정합) 우선 |
| **ChatGPT 대체재 위협** | "그냥 ChatGPT에 물어보면 되지" — 무료 범용 대체재 존재 | 물리 셔플 + 맥락 지속성 + 해석 사조 선택 = "범용 챗봇으로 불가능한 경험" 차별화 |

## 3. 핵심 의사결정 기반 (후속 구현 파이프라인 입력)

### 3.1 LLM 선택

| 항목 | 추천 | 근거 |
|------|------|------|
| 1차 모델 | **Claude Sonnet 4.6** | $3/$15/MTok, 1M 컨텍스트, 90% 캐시 절감, 뉘앙스 있는 한국어 |
| 경량 모델 | Claude Haiku 4.5 | $0.25/$1.25/MTok, 무료 티어용 |
| 대안 | GPT-4.1 | $2/$8/MTok, 47% 저렴 — LLM Provider 추상화로 교체 유연성 확보 |
| 오픈소스 | Llama 3 405B | 셀프 호스팅 고려 시 — 초기 단계에서는 불필요 |

### 3.2 프롬프트 아키텍처

**5레이어 구조** (캐싱 최적화):
1. **페르소나/전통** (캐시 고정) — 해석 스타일, 사조(심리학적/상징학적/영적)
2. **카드 레퍼런스** (캐시 고정) — 78장 카드 데이터, 수트 특성
3. **유저 프로필** (세션 캐시) — experienceLevel, 성격 유형(향후), 선호 사조
4. **현재 리딩** (요청별) — drawnCards, question, spreadType, isReversed
5. **대화 히스토리** (턴별) — 슬라이딩 윈도우, 요약 히스토리

### 3.3 맥락 지속성 로드맵

| 단계 | 방식 | 구현 복잡도 |
|------|------|-----------|
| MVP | Sliding Window (최근 N턴 유지) | 낮음 |
| Phase 2 | + Hierarchical Summary (긴 대화 요약) | 중간 |
| Phase 3 | + RAG with pgvector (과거 리딩 검색·주입) | 중간~높음 |

### 3.4 멀티모달 로드맵

| 단계 | 출력 형태 | 추가 비용/회 | 기술 |

| MVP | 텍스트 채팅 + 인앱 카드 리포트 | $0 (인앱 렌더링) | Flutter 위젯 |

| Phase 4 | + 영상 (탐색적) | ~$0.25 | Runway / Pika |

### 3.5 포지셔닝

## 4. personality 삼각 차별화 모델

```
                    물리 셔플 엔진
                   (유일한 하드 차별화)
                        /\
                       /  \
                      /    \
                     /      \
                    / 체화된  \
                   /  의식    \
                  /   경험     \
                 /              \
맥락 지속성 ─────────────────── ReflectivePrompts
(리텐션 드라이버)              (품질 차별화)
 과거 리딩 참조                바넘 효과 방어
 성장 추적                     자기 성찰 유도
 개인화 심화                   개인화 입력 수집
```

이 삼각 구조의 강점: 세 축이 상호 강화
- 물리 셔플 → DrawnCardInfo → AI 프롬프트 입력 (기술 정합)
- ReflectivePrompts → 사용자 응답 → 맥락 데이터 축적 (개인화 루프)
- 맥락 지속성 → 과거 리딩 참조 → 더 깊은 해석 (품질 향상 루프)
