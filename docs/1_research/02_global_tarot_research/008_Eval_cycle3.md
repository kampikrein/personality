# Eval — Cycle 3 사용자 문화·행동 & 페르소나 기초

## 평가 대상

- 문서: `005_Research_user_culture.md`
- Scope 사이클 3 핵심 질문: 문화 배경, 사용자 동기, 이용 스타일, 규제 환경

---

## 1. Completeness (완결성) — 9/10

5개 권역 모두에 대해 아래 항목을 빠짐없이 다룸:
- 문화적 뿌리 (전통 점술 체계와 타로 융합 양상)
- 사용자 동기 (7가지 유형 × 5개 권역 매트릭스)
- 이용 스타일 (4가지 유형 × 5개 권역 비중 추정)
- 인구통계 (연령, 성별, 플랫폼, 결제 의향)
- 규제 환경 (권역별 법적 지위, 플랫폼 규제, 데이터 규제)

**미흡점**: EU 내 국가별 편차(영국 vs 프랑스 vs 독일 vs 북유럽)가 개괄 수준에 머무름. 단, Scope에서 EU를 단일 권역으로 정의했으므로 범위 내 충분.

## 2. Data Quality (데이터 품질) — 7/10

**강점**:
- Pew Research(2024, 9,593명), 矢野経済研究所(2024), TikTok/더우인 조회수 등 구체적 출처 명시
- 한계 섹션(2.2)에서 데이터 한계를 4가지 항목으로 자기 점검

**미흡점**:
- 이용 스타일 비중(섹션 5)이 "추정"으로만 표기되어 근거가 불명확. 어떤 데이터에서 도출했는지 알 수 없음
- 세션 패턴(시간, 빈도, 시간대)도 출처 없이 수치 제시 — 추정이면 추정임을 명시해야 함
- KR "72~80%" 수치의 출처가 본문 맥락에서만 유추 가능 (조세일보/한국경제 추정)

→ synthesis에서 이 수치들을 "추정치"로 명시하면 충분. 재조사 불필요.

## 3. Scope Alignment (Scope 정합성) — 9/10

Scope 사이클 3 핵심 질문 4가지에 대한 커버리지:

| 핵심 질문 | 커버 여부 | 비고 |
|-----------|:---------:|------|
| 권역별 타로 문화 배경 | ✅ | 섹션 3, 5개 권역 각각 상세 |
| 사용자 동기 | ✅ | 섹션 4, 7유형 × 5권역 매트릭스 |
| 이용 스타일 | ✅ | 섹션 5, 4유형 × 5권역 + 세션 패턴 |
| 규제 환경 | ✅ | 섹션 7, 5개 권역 개별 테이블 |

Scope 산출물 요구사항("권역별 사용자 프로필 + 동기-스타일 매트릭스 + 규제 요약") 모두 충족.

## 4. Brief Alignment (Brief 정합성) — 8/10

**충족 항목**:
- 3축 구조(권역 × 서비스유형 × 이용스타일) 검증 완료 (섹션 9.2)
- 권역당 2~3개 페르소나, 총 13개 (Brief Decision #5의 "10~15개" 범위 내)
- 데이터 기반 지배적 조합 선별 (섹션 8.1)
- 경쟁사 포함 비교 관점 반영 (서비스 유형 선호에 구체적 경쟁 앱 명시)

**경미한 갭**:
- JP가 2개 페르소나로 Brief 하한(2개)에 걸림. "남성 이용자 증가 추세"를 반영한 3번째 JP 페르소나가 있으면 더 완전했을 것
- EU도 2개. 국가별 편차를 고려하면 영국/프랑스/독일 각 1개씩 있어도 무방했으나, 현 2개가 학습형/영적형이라는 EU 핵심 분화를 잘 포착

→ 페르소나 수 부족은 synthesis 단계에서 보완 가능. 차단 사유 아님.

## 5. Actionability (실행 가능성) — 8/10

- Incremental Summary(섹션 10)가 9개 항목으로 핵심 발견을 압축 — synthesis 입력으로 즉시 활용 가능
- 페르소나 프로필이 ID/권역/동기/스타일/서비스유형/연령/성별/결제의향을 포함한 구조화 테이블 제공 (섹션 8.4)
- 자사 서비스 시사점(섹션 9.1)이 5개 항목으로 actionable recommendation 제공
- 3축 프레임워크 유효성 검증 + 4번째 축(동기) 처리 방안 제안 (섹션 9.2)
