# 글로벌 타로 앱 시장 조사 종합

## 1. Executive Summary

3개 연구 축(시장 현황·서비스 분류·사용자 문화)의 교차 분석에서 도출된 핵심 결론:

1. **글로벌 공통 미충족 니즈**: "제의적 셀프 리딩 경험"(물리적 셔플, 카드 선택 의식)을 디지털로 완전 구현한 앱이 **어떤 권역에도 부재**
2. **KR = 최적 1차 시장**: 사주 과점 시장에서 타로 전용 앱 공백 + MZ세대 72% 집중 + 이벤트형 이용 패턴 = personality 서비스의 차별화 공간
3. **AI + 맥락 지속성 = 글로벌 차별화**: 모든 권역에서 AI 해석이 차세대 물결이나, 세션 간 기억 부재가 공통 약점
4. **권역별 프레이밍 필수**: 동일 서비스도 KR(위안), US(웰니스), JP(연애), CN(감정컨설팅), EU(문화유산) 프레이밍으로 포지셔닝 분화 필요
5. **13개 페르소나 + 7차원 평가 프레임워크** 확정 — 자사 서비스 다각 평가 시뮬레이션 즉시 실행 가능

## 2. 3축 교차 분석

### 2.1 축 수렴 — 3축이 동시에 가리키는 기회

| 수렴 패턴 | 시장(축1) | 서비스(축2) | 문화(축3) | 시사점 |
|----------|----------|-----------|----------|--------|
| **KR 타로 전용 공백** | 타로 전용 앱 극소, 수요/공급 중간 | 종합형 포화, 셀프리딩형 부재 | 이벤트형+위안 동기 지배 | 셔플 의식 + AI 해석 결합이 KR에서 최적 차별화 |
| **글로벌 셔플 UX 부재** | 모든 권역에서 "탭하여 선택" 수준 | 셀프리딩형·종합형 모두 물리 셔플 미구현 | 일상습관형·영적실천자 모두 의식(ritual) 기대 | Flutter 셔플 엔진이 유일한 글로벌 차별화 자산 |
| **AI 맥락 단절 문제** | AI 타로 33+개(US)이나 동질화 | AI해석형 최고 성장이나 실패 패턴 1위 = 맥락 단절 | 이벤트형은 1회성이나 학습형·일상형은 연속성 기대 | AI 맥락 유지 = 학습형·일상형 사용자 리텐션 핵심 |
| **구독 피로 + 대안 모델** | 구독이 매출 45%이나 피로 도래 | 라이브(분당)·AI(크레딧) 대안 성장 | KR=건별, CN=소액IAP, JP=종량제 선호 | 하이브리드 수익 모델(프리미엄+크레딧+선택구독) |

### 2.2 축 긴장 — 3축이 충돌하는 지점

| 긴장 패턴 | 설명 | 해결 방향 |
|----------|------|----------|
| **학습 vs 위안** | US/EU는 학습형 최강(Labyrinthos 4.9), KR/CN은 학습형 약세 — 동일 콘텐츠 전략 불가 | KR 진입 시 "위안 → 학습" 그래디언트, 글로벌 확장 시 "학습" 전면 배치 |
| **연애 특화 vs 자기 탐구** | JP 85% 연애 동기 vs personality 미션("자기 이해") | JP 진입 시 "관계 이해"로 브릿지 — 자기 이해의 관계적 측면 강조 |
| **규제 vs 수요** | CN 수요 폭발(DAU 500만+) vs 미신 규제 직접 차단 | CN 우선순위 하향. 진입 시 "성격 인사이트" 프레이밍 + 위챗 미니프로그램 |
| **프리미엄 디자인 vs 대중 접근성** | EU 고가 결제의향(연간 €50~80) vs CN 소액(1~10위안) | 단일 가격 정책 불가 — 권역별 가격 계층화 필수 |

### 2.3 수요/공급 × 서비스유형 × 문화 교차 매트릭스

```
         공급 Low              공급 Med            공급 High
수요 H  │ CN: AI해석 폭발     │                   │ US: 다유형 포화    │
        │ 규제 억제→공급↓     │                   │ 학습+AI+라이브     │
        │ 문화: 소셜+이벤트    │                   │ 문화: 웰니스+자기탐구│
수요 M  │ EU: 셀프리딩+학습    │ KR: 타로전용 공백  │ JP: 라이브 중심    │
        │ 디지털전환 초기      │ 사주과점, MZ 집중   │ 占い 생태계 고착    │
        │ 문화: 학습+영적      │ 문화: 위안+이벤트   │ 문화: 연애+일상     │
수요 L  │                     │                   │                   │
```

## 3. 에이전트 페르소나 확정 (13개)

### 3.1 페르소나 설계 원칙

- **3축 프레임워크**: 권역(문화) × 서비스유형선호 × 이용스타일
- **동기는 권역의 내재 속성**: 4번째 독립 축이 아닌 권역 문화에서 파생 (Cycle 3 검증)
- **데이터 기반 지배적 조합만 선별**: 3축 전체 조합(5×7×4=140) 중 실제 데이터가 지지하는 13개
