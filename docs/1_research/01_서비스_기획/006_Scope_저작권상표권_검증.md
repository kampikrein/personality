# MBTI·애니어그램 저작권/상표권 등록 현황 검증

## 작업 목표

1. MBTI와 애니어그램의 저작권/상표권 **실제 등록 현황** 검증
2. "애니어그램(Enneagram)" 용어 사용 자체의 법적 리스크 확인
3. personality 서비스의 현재 법적 가이드라인(에이전트 레드라인)이 정확한지 교차 검증

## 접근 방향

기존 연구 문서(002, 003)를 베이스로 활용하되, **외부 소스로 교차 검증**:
- USPTO/KIPRIS 상표 등록 데이터베이스 검색
- Arica v. Palmer 판례 원문 확인
- 최신 한국 판례/법률 의견 확인
- 에이전트 프롬프트의 레드라인 항목과 법적 현실 대조

## Research 판단

- **판단**: 필요
- **근거**: 기존 문서는 Gemini Deep Research 기반. 실제 등록 DB와 판례 원문으로 교차 검증해야 서비스 운영에 충분한 확신. 특히 "Enneagram" 용어의 상표 등록 여부는 기존 문서에서 명시적으로 다루지 않음.
- **파이프라인**: S → R (순수 연구/검증 — 구현 없음)

## 기존 연구 요약 (002, 003에서)

### MBTI — 강력한 보호
- **상표권**: "MBTI", "Myers-Briggs", "Myers-Briggs Type Indicator" 등록 상표
- **저작권**: 93개+ 검사 문항, 결과 리포트 보호
- **공공영역**: Jung의 심리 유형론 자체, 4글자 유형코드(INTJ 등)
- **한국**: 어세스타(한국 MBTI 연구소)가 한국 내 권리 보유

### 애니어그램 — 구조는 공공영역, 표현은 보호
- **공공영역**: 9유형 구조, 유형 명칭 (Arica v. Palmer, 2nd Circuit)
- **저작권 보호**: 특정 검사 도구(KEPTI), 개별 저자의 서술/해석
- **핵심 판례**: 금반언 원칙 — "사실로 홍보한 것을 창작물로 주장할 수 없다"
