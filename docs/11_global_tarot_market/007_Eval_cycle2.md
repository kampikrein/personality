# Eval — Cycle 2 서비스 분류

## 1. 평가 요약

Cycle 2 연구 산출물(004)은 Scope에서 요구한 4개 핵심 질문(서비스 유형 분류, 권역별 대표 앱, 차별화 요소, 비즈니스 모델)을 모두 다루고 있으며, Brief의 최종 목표(에이전트 페르소나 설계 + 평가 프레임워크)에 필요한 기초 데이터를 충분히 제공한다.

## 2. 차원별 평가

### Completeness (9/10)

- **택소노미**: 7개 기본 유형 + 2개 하위/신흥 유형(감성웰니스, 크리에이터) 식별. 유형 간 관계도까지 제시. Scope 요구("AI 해석형, 라이브 리딩형, 셀프 리딩형, 학습형, 소셜형, 종합형")를 모두 포함하고 일일운세형을 추가로 분리.
- **앱 프로필**: KR 7개, US 10개, JP 7개, CN 8개, EU 7개 = 총 39개. Scope 기준(Top 5~10) 충족.
- **교차 매트릭스**: 유형-권역 매트릭스(5.1), 권역별 지배 유형(5.2), 교차 인사이트 5개(5.3) 모두 산출.

### Data Quality (7/10)

- **구체성**: 앱별 평점, 사용자 수, 매출 추정치, 차별점이 기재됨. 헬로우봇(150~200억원), Nebula($7M+), 测测(수년간 흑자) 등 수치 포함.
- **소스**: 방법론 섹션(2.1)에 데이터 소스 유형 명시. 개별 수치에 출처(AI타임스, Statista, 36kr 등) 일부 기재.
- **감점 요인**: CN/EU 일부 앱의 평점·사용자 수가 "-"로 미기재. 시장 점유율(6.1)은 "추정"으로 명시되나 추정 근거가 불명확. 개별 앱 프로필의 출처가 일괄 기재 방식이라 특정 수치의 검증 경로가 불분명한 경우 있음.

### Scope Alignment (9/10)

Scope Cycle 2 핵심 질문 4개에 대한 충족도:

| 핵심 질문 | 충족 | 비고 |
|----------|:----:|------|
| 서비스 유형 분류 | O | 7+2 유형, 정의 매트릭스, 관계도 |
| 유형별 대표 앱 + 기능/UX/비즈니스 모델 | O | 39개 앱 프로필 카드 |
| 권역별 지배 유형 차이 | O | 매트릭스 + 교차 인사이트 |
| 차별화 요소(높은 평점 상관) | O | 7.1 성공 패턴, 7.2 실패 패턴 |

요구 산출물("서비스 유형 택소노미 + 권역-유형 매트릭스 + 앱별 프로필 카드") 3개 모두 존재.

### Brief Alignment (8/10)

- **페르소나 설계 기여**: 권역별 지배 유형(5.2)과 사용자 프로필(3.1)이 3축(권역 x 유형 x 스타일) 중 2축(권역, 유형)의 데이터를 제공. 이용 스타일은 Cycle 3 영역이므로 적절한 분업.
- **평가 프레임워크 기여**: 차별화 요소(7.1), 실패 패턴(7.2), 비즈니스 모델 분석(6장)이 평가 차원 설계의 기초 자료로 활용 가능.
- **자사 시사점**: 8장에서 personality 프로젝트와의 연결점 8개를 명시적으로 도출. Brief Decision #7(즉시 반영 병행)에 부합.

### Actionability (8/10)

- **Incremental Summary**: 9장에 압축된 요약 제공. Synthesis에서 Cycle 1/3과 교차 가능한 형태.
- **매트릭스 구조**: 유형-권역 매트릭스(5.1)가 시각적으로 명확. ●~●●●● 스케일 사용.
- **개선 여지**: 비즈니스 모델 시장 점유율의 추정 근거가 보강되면 Synthesis에서의 신뢰도가 높아질 것. 다만 이는 minor issue.
