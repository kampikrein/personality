## 1. 에이전트 간 교차 합의점

5개 에이전트의 독립 분석에서 **자연스럽게 수렴한 3가지 핵심 합의**:

### 합의 1: Level 1 카드 = 최우선 과제
| 에이전트 | 관련 발견 |
|---------|----------|
| mbti-expert | "Level 1 부재가 가장 치명적인 갭. seeds.rb로 즉시 20개+ 제작 가능" |
| uiux-expert | "성격검사를 진입점으로 강제하지 말 것. 카드 피드가 첫 경험이어야" |
| enneagram-expert | "MBTI 카드 → '왜 이런지 알고 싶다면' 애니어그램 진입 훅" |
| coding-expert | "ContentCard 모델 설계가 V2 전제조건" |

### 합의 2: 스펙트럼 시각화 = 핵심 차별화
| 에이전트 | 관련 발견 |
|---------|----------|
| psychology-expert | "MBTI 재검사 유형 변경 50%. 스펙트럼이 가장 강력한 단일 차별화" |
| mbti-expert | "16유형 고정 라벨이 아닌 성향 스펙트럼으로 접근" |
| uiux-expert | "결과 카드 시퀀스 7장에 스펙트럼 바 시각화 포함 가능" |

### 합의 3: 호기심 갭 = 리텐션 핵심
| 에이전트 | 관련 발견 |
|---------|----------|
| mbti-expert | "Hook & Bridge 구조: 현재 콘텐츠가 다음 콘텐츠를 예고" |
| uiux-expert | "쇼츠 중독성의 핵심은 끝없는 피드가 아니라 호기심 갭" |
| enneagram-expert | "MBTI → 애니어그램 → 날개 → 본능 → 건강수준 = 5단계 깊이 탐색" |
| psychology-expert | "Loewenstein(1994) 정보 격차 이론: 학술 정보도 호기심 도구" |

## 2. 4-Phase 실행 로드맵

### Phase 0: 기반 안정화 (2주)

| # | 작업 | 담당 | 이유 |
|---|------|------|------|
| 0-1 | 7개 미테스트 서비스 스펙 작성 | coding-expert | 646줄 미검증 코드가 프로덕션 경로에 있음 |

## 3. 즉시 시작 가능한 첫 번째 작업 세트

Phase 0의 3개 작업은 **서로 독립적이므로 병렬 실행 가능**:

```
[병렬 실행]
├── coding-expert: 7개 미테스트 서비스 스펙 작성
├── mbti-expert: personality_types 시드 16개 콘텐츠 완성
└── psychology-expert: 임상 경계 가드레일 표준화 문서
```

Phase 0 완료 후 Phase 1-1 ~ 1-6도 상당 부분 병렬 진행 가능.

## 5. 위험 요소와 가드레일

| 위험 | 출처 | 가드레일 |
|------|------|----------|
| 학술 깊이가 재미를 해침 | psychology | 학술 레이어는 항상 opt-in. 기본 경험을 방해하지 않음 |
| 바넘 효과 의존 | psychology | 행동 빈도 + 맥락 특정성 + 조건부 서술로 대체 |
| 자기 진단 위험 | psychology | "진단이 아닌 참고용" 고지 표준화 (Phase 0) |
| 유사과학 오인 | psychology | 타로/사주 확장 시 심리학 콘텐츠와 명확 분리 |
| 저작권 침해 | mbti | MBTI 공식 문항 0% 중복 유지 + 독자적 문항 |
| 기술 부채 누적 | coding | Phase 0에서 미테스트 먼저 해결 |
